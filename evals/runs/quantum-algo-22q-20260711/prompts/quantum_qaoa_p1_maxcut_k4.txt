Write a complete, runnable Python program using Qiskit 2.x that:
1. Builds the 4-vertex graph with edges (0,1), (1,2), (2,0), (2,3)
   (a triangle 0-1-2 plus a pendant edge 2-3). The Max-Cut optimum is 4
   (cut {0,2} | {1,3} or {0,3} | {1,2}).
2. Implements QAOA with p=1: build the cost Hamiltonian
   H_C = sum_{(i,j) in edges} (1 - Z_i Z_j) / 2  (as a SparsePauliOp, with
   the correct sign so that maximizing H_C corresponds to maximizing the cut).
   Build the mixer H_M = sum_i X_i. Construct the QAOA ansatz
   |gamma, beta> = e^{-i beta H_M} e^{-i gamma H_C} |+>^n with p=1.
3. Optimizes the parameters (gamma, beta) using scipy.optimize.minimize
   (e.g. Nelder-Mead, 50 iterations, 5 random restarts) and the
   StatevectorEstimator to evaluate <H_C> at each step.
4. After optimization, sample the QAOA state with StatevectorSampler
   (>= 4000 shots), compute the cut value for each measured bitstring,
   and report the maximum cut value found.
5. In `def main()`, prints:
     cut_value = <integer>
     optimal: True   (if cut_value == 4 else False)
   Expected: cut_value = 4 and optimal: True.
Call main() under `if __name__ == "__main__":`.

Write a complete, runnable Python program using Qiskit 2.x that:
1. Implements quantum teleportation across a 3-qubit chain (qubit 0 = data, qubits 1-2 = Bell pair).
2. The data qubit 0 is prepared in |psi> = |+> = (|0>+|1>)/sqrt(2) via H.
3. The Bell pair on qubits 1,2 is prepared via H on qubit 1 then CNOT(1,2).
4. Applies the teleportation protocol: CNOT(0,1), H(0), then a computational basis measurement
   of qubits 0 and 1 (the Bell measurement).
5. Simulates the post-measurement state of qubit 2 conditional on each (m0,m1) outcome,
   applies the classical correction X^m1 Z^m0 to qubit 2, and computes the fidelity with |psi>.
   Average the fidelity weighted by the probability of each outcome.
6. In `def main()`, prints:
     fidelity = <value rounded to 3 decimals>
     teleported: <True|False>
   Expected: fidelity ≈ 1.000, teleported: True (fidelity > 0.99).
Call main() under `if __name__ == "__main__":`.

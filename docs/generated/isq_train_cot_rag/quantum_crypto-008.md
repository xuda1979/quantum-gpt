量子中继器与量子纠错（QEC）在理论和工程上相辅相成。一方面，中继器内部使用的“纠缠纯化”协议，本质上就是利用少量的局部量子操作来提取出高保真度的纠缠态，这与量子纠错码中通过测量伴随式来提取并纠正错误的逻辑高度一致。另一方面，在所谓的“三代量子中继器”架构中，直接使用了量子纠错码来保护飞行量子比特和存储量子比特。中继器节点中的量子存储器必须具备容错能力，这就要求将中继器的控制逻辑与表面码等量子纠错算法深度结合。

3. **盲量子计算**：
在隐私保护的计算场景中，资源受限的客户端希望利用远程的大型量子服务器进行计算，但不希望泄露自己的数据和算法。量子中继器提供的长距离量子信道使得客户端可以与远端服务器建立量子纠缠，进而实现量子隐形传态。客户端只需进行简单的单比特测量，就能通过中继网络控制远端服务器执行复杂的量子电路，这正是盲量子计算协议的物理基础。

    int r1 = M(q[1]);

    // 根据 r1 和 r2 的结果，Alice 和 Bob 可以通过经典的局域操作

    if (r2 == 1) {
        X(q[0]);
    }
    if (r1 == 1) {
        Z(q[0]);
    }

### Reference answer

量子安全直接通信（Quantum Secure Direct Communication, 简称 QSDC）是量子密码学中的一个重要通信范式。从严谨的物理学与数学角度来定义：QSDC 是一种利用量子力学基本原理（如量子不可克隆定理、测量坍缩或量子纠缠的非局域性）在存在潜在窃听者的量子信道中，直接、安全地传输机密信息，而通信双方无需事先建立和共享经典密钥来加密明文的通信过程。

在数学模型上，我们可以将 QSDC 抽象为一个量子信息处理协议。设发送方 Alice 欲传输的明文消息空间为 $\mathcal{M}$，其中消息 $m \in \mathcal{M}$。Alice 通过一个依赖消息的量子编码操作 $\mathcal{E}_m$ 作用于预共享的纠缠态或制备的量子态上，将经典信息 $m$ 映射到特定的量子态系综 $\{\rho_m\}$ 上。这通常对应于一组酉变换 $\{U_m\}$ 或特定的调制操作。随后，量子态在物理信道中演化并被接收方 Bob 接收，Bob 通过执行一组正定算符值测度（POVM） $\{\Pi_k\}$ 对系统进行解码，得到对原消息的估计值 $\hat{m}$。

QSDC 的核心安全性可以用信息论的语言进行精确的数学表述。对于一个 $(n, \epsilon_{sec}, \epsilon_{cor})$-QSDC 协议，必须满足以下条件：

1. **零信息泄漏**：在理想情况下，对于任何采用局部操作与经典通信（LOCC）的窃听者 Eve，其拥有的辅助系统态 $\rho_E$ 与传输的消息 $m$ 之间是相互独立的。用互信息的数学语言表述，即要求窃听者获取的信息量严格趋于零：
$$ I(M : E) = 0 $$
对于存在噪声的实际信道，在块传输（Block Transmission）和随机抽样检测后，只要信道误码率低于安全阈值 $e_{th}$，必须保证对于任意两个不同的消息 $m, m' \in \mathcal{M}$，Eve 所截获的量子态的迹距离必须满足：
$$ \frac{1}{2} \| \rho_E^m - \rho_E^{m'} \|_{\text{tr}} \le \epsilon_{sec} $$
其中 $\epsilon_{sec}$ 是一个可忽略的极小值，这从物理上确保了 Eve 无法在统计上区分不同消息对应的量子态演化。

2. **正确性**：在无窃听的理想量子信道中，Bob 解码得到错误消息的概率必须满足 $P_e = \Pr(\hat{m} \neq m) \le \epsilon_{cor}$。

**与量子密钥分发（QKD）的本质区别：**
从信息论和物理学角度来看，QKD 的安全性定义在于通信双方最终提取的密钥字符串 $K$ 与 Eve 拥有的任何物理系统之间的互信息趋于零，即 $I(K : E) \approx 0$，其传输的是“随机性”和“共享状态”。而 QSDC 传输的则是“有意义的信息”本身，其安全性定义不仅要求窃听者无法解码，更要求在物理传输过程中，明文信息不会因窃听行为而泄漏到环境中。QSDC 必须在物理层面实现信息率泄漏 $I(M;E)$ 为零的前提下，维持正向的信息传输率 $R > 0$，这是将密钥生成与安全通信合二为一的更为严格的物理约束。

### Reference answer

在量子密码学领域，量子密钥分发的“无条件安全性”（Unconditional Security），亦称为信息论安全性，是指该密码协议的安全性证明仅依赖于量子力学的基本物理定律，而不依赖于窃听者计算能力的任何假设（如传统的计算复杂性假设）。这种安全性主要由两个核心定理共同保证：一是海森堡不确定性原理，二是量子不可克隆定理。量子不可克隆定理严格证明了不存在一个合法的酉操作能够完美复制任意的未知量子态，这意味着窃听者无法在不扰动系统的情况下提取密钥信息。从现代密码学的形式化框架来看，QKD的最终目标是确保生成的长度为 $n$ 的最终密钥 $K$ 在统计上与一个完全均匀分布的真随机比特串不可区分，同时与窃听者在此前所有交互过程中可能获取的任何经典或量子信息（即辅助系统 $E$）完全解耦。这一隔离关系在数学上必须通过密度矩阵的语言来严格表述。假设窃听者所掌握的全部辅助系统状态由密度矩阵 $\rho_E$ 描述，而最终的理想密钥应当是一个处于最大混合态的完全随机变量 $\rho_K^{ideal} = \frac{I}{2^n}$。如果协议的实际输出状态是由密钥空间和窃听者辅助空间构成的复合量子系统 $\rho_{KE}$，那么我们称该协议是 $\epsilon$-安全的，当且仅当实际复合状态与理想状态之间的量子迹距离严格小于一个极小的安全参数 $\epsilon$：

$$ \frac{1}{2} \left\| \rho_{KE} - \left( \frac{I}{2^n} \otimes \rho_E \right) \right\|_1 \le \epsilon $$

这里的迹距离在物理本质上度量了对这两个量子态进行最优量子测量时猜测正确的最大概率差。只要上述不等式成立，即可严密推导出窃听者利用任何基于量子力学的攻击策略猜中密钥任意部分的概率优势，将随密钥长度的增加而呈指数级衰减。在实际的安全参数估计中，量子误码率（QBER）的物理观测起着决定性作用。协议通过在量子信道上随机比对部分抽样比特的误码率上限 $e$，利用量子相干信息的下界或平滑极小熵公式，定量限制窃听者可能获取的最大互信息量：

$$ H_{min}^{\epsilon}(A|E) \ge n \left( 1 - h(e) \right) $$

其中 $h(e)$ 为二元熵函数。只要观测到的误码率低于协议的容错阈值（例如BB84协议在单光子源下约为11%），Alice和Bob就能利用经典后处理技术（包括信息调和隐私放大），从 $n$ 个原始比特中安全地提取出足够长度的最终密钥。经过通用哈希函数的压缩映射后，被压缩掉的冗余信息将彻底摧毁窃听者系统与最终密钥之间的残余量子纠缠，从而在物理定律和数学双重层面上确立无条件安全性的封闭证明。

这个说法包含了一个在量子密码学中非常经典的直觉陷阱。其错误之处在于：它将“量子不可克隆定理（无法完美复制未知量子态）”错误地等同于了“无法进行任何测量或窃听”。事实上，Eve完全可以对传输中的光子强行进行测量从而获取部分信息，她绝对不是只能“一无所获地离开”。这个说法的致命误区在于忽略了量子测量导致的坍缩以及Eve可能采取的“截获-测量-重发”攻击策略。

在BB84协议中，Alice会随机选择两组互不相干的基（例如计算基Z {|0⟩, |1⟩} 和对角基X {|+⟩, |-⟩}）之一来编码并发送光子。当窃听者Eve拦截到光子时，由于量子不可克隆定理，她确实无法制造出一个完美的副本备份然后把原件悄悄放回信道。但是，Eve完全可以“强行”对这个光子进行测量。

当Eve进行测量时，她必须自己随机猜一个测量基。这里有两种情况：
1. 如果Eve恰好猜对了Alice使用的基（概率为50%），比如Alice发送的是Z基下的|0⟩，Eve也用Z基测量，那么Eve不仅准确获取了密钥比特（0），而且她可以将光子重新按照|0⟩发送给Bob。在这种情况下，Eve的窃听完全没有引入错误，Alice、Bob和Eve共享了相同的密钥比特。
2. 如果Eve猜错了基（概率为50%），比如Alice发送的是X基下的|+⟩，而Eve用Z基去测量。根据量子力学，测量会导致量子态发生随机坍缩，Eve有50%的概率测得|0⟩，50%的概率测得|1⟩。假设Eve测得了|1⟩，她就获取了错误的密钥信息，更致命的是，当她把|1⟩发送给Bob时，如果Bob此时恰好使用与Alice相同的X基进行测量，Bob将有50%的概率把|1⟩错测成|-⟩（即比特1），这就导致Alice原本发送的是0（对应|+⟩），Bob却收到了1（对应|-⟩）。

综合来看，在Alice和Bob最终筛选出使用了相同基的比特串中，Eve的这种截获-重发行为会不可避免地引入25%的量子误码率（QBER）。因此，Eve不仅能拿到部分密钥信息，而且正是因为她能够拿到信息，物理定律才强制要求她必须破坏部分量子态。BB84协议的安全性并非建立在“Eve拿不到信息”上，而是建立在“Eve获取信息的代价是不可避免地留下误码痕迹，从而被合法通信方发现”这一原理之上。

### Reference answer

<tooltip>
在经典随机预言机模型（ROM）中，哈希函数被视为一个完美的公共随机函数。当安全归约模拟器试图将敌手的攻击能力转化为解决底层数学难题（如LWE问题）的能力时，通常会采用“可提取性”技术。模拟器通过记录敌手的查询-应答列表，在敌手成功伪造或解密后，提取出关键信息。

然而，在量子随机预言机模型（QROM）中，敌手可以生成一个包含所有可能输入的量子叠加态，并将其发送给哈希预言机进行查询：
$$|\psi\rangle = \frac{1}{\sqrt{2^n}} \sum_{x \in \{0,1\}^n} |x\rangle |0\rangle \xrightarrow{H} \frac{1}{\sqrt{2^n}} \sum_{x \in \{0,1\}^n} |x\rangle |H(x)\rangle$$
敌手仅凭一次量子查询，就获得了指数级数量输入的哈希值叠加态。此时，如果模拟器试图通过测量敌手的查询寄存器来提取某个具体的明文 $x_0$，量子力学原理表明，测量会导致叠加态坍缩到某一个基底态上，概率极低（约 $1/2^n$），并且这种坍塌会不可逆转地破坏敌手的内部量子态，导致后续归约无法继续。同时，经典归约中的“可编程性”要求模拟器在看到敌手的查询后再设置哈希值，但在量子并行查询下，敌手瞬间查询了所有值，模拟器无法针对特定的未查询点进行后门嵌入，因为对哈希函数任何局部的修改都会影响整个叠加态的酉变换演化。

这是一个触及现代密码学安全证明灵魂的深刻问题。在后量子密码学（PQC）中，仅仅使用经典的安全假设是不够的，必须确保安全归约本身能够抵御拥有量子计算能力的敌手，这就是量子随机预言机模型（QROM）不可或缺的根本原因。

在经典密码学中，我们常常假设哈希函数是一个完美的随机预言机。当证明一个方案（如基于格的数字签名或密钥封装机制）的安全性时，模拟器会通过“可提取性”和“可编程性”来构造归约：模拟器记录敌手的每一次哈希查询，或者根据敌手的查询动态修改哈希函数的输出，从而将敌手的攻击行为转化为解决底层困难问题（如格上的最短向量问题）的算法。

然而，量子敌手打破了这套经典的游戏规则。在QROM中，敌手可以利用量子叠加态进行哈希查询。这意味着敌手不再逐个查询哈希值，而是可以将所有可能的输入编码在一个量子态中，通过一次酉变换同时获取所有输入对应的哈希值叠加态。这种指数级的并行查询能力直接摧毁了经典ROM的两大支柱：

1. **破坏可提取性**：在经典ROM下，如果敌手成功伪造了消息签名，模拟器可以通过查阅历史记录，提取出敌手之前查询过的哈希输入。但在QROM下，敌手的查询是叠加态。如果模拟器试图测量敌手的量子寄存器以提取信息，量子态会发生随机坍缩。这不仅只能以极微小的概率提取到正确的输入，还会彻底破坏敌手的相干性，导致模拟器无法继续运行敌手的攻击算法，归约因此断裂。

2. **破坏可编程性**：经典归约往往依赖于“后知后觉”的编程，即模拟器在看到敌手挑战后才去修改哈希函数的值。但在量子叠加查询面前，敌手可能在游戏开始的第一步就已经查询了所有的点。模拟器无法在不改变其他叠加分支计算结果的前提下，精准地“编程”某一个特定分支的哈希输出。任何局部的修改都会通过量子干涉效应影响整个叠加态的演化，导致敌手察觉到模拟器与现实环境的差异。

综上所述，一个后量子密码方案如果仅仅在经典ROM下被证明安全，这意味着它在理论上可能无法抵御利用量子叠加态进行的降维打击。将证明扩展到QROM，尽管在数学和密码学工程上极具挑战性（通常会导致更紧的安全归约损失），但这是确保密码学协议在面对未来量子计算机时依然坚如磐石的唯一严谨途径。

3. 量子传输层

### Reference answer

量子数字签名是经典数字签名在量子信息领域的密码学原语扩展。严格来说，量子数字签名是一种基于量子力学原理设计的通信协议，旨在为数字消息提供不可伪造性和不可抵赖性的信息论安全保护，其安全性不依赖于计算复杂性假设（如大整数分解或离散对数难题），而是直接由量子物理的基本定律作保证。

从学术定义的层面来看，一个完善的量子数字签名协议（QDS）由三个概率多项式时间算法组成：密钥生成、签名生成与签名验证，其核心在于利用量子态作为签名载体或验证凭证。

区别于经典数字签名，QDS的安全性基石主要依赖于以下两个核心物理定理：
1. **量子不可克隆定理**：在量子力学中，不存在一个幺正算符 $U$ 能够对任意未知量子态 $|\psi\rangle$ 实现完美的复制，即 $U(|\psi\rangle \otimes |e\rangle) \neq |\psi\rangle \otimes |\psi\rangle$。在QDS中，这保证了攻击者无法截获并完美复制包含签名的量子态以进行重放或分发，从根本上杜绝了签名的完美伪造。
2. **海森堡不确定性原理与非正交态的不可区分性**：由于不同的签名密钥通常编码为非正交的量子态集 $\{|\phi_i\rangle\}$，任何试图区分或测量这些未知量子态的窃听行为，都会不可避免地引入大于零的扰动误差 $\epsilon > 0$。这一性质使得合法接收方在验证阶段能够以极高的概率检测到篡改行为。

在信息论安全性的数学表达上，一个安全的QDS方案必须满足两个核心性质：
- **不可伪造性**：对于拥有无限计算能力的敌手 $\mathcal{A}$，在已知除目标消息 $m$ 之外的签名信息条件下，成功伪造出消息 $m$ 的有效量子签名 $\sigma_m$ 的概率是一个可忽略函数 $\epsilon(n)$，即：
  $\Pr[\text{Verify}(pk, m, \sigma_m) = 1 \mid (m, \sigma_m) \leftarrow \mathcal{A}(1^n, pk)] \leq \epsilon(n)$
  其中 $\epsilon(n)$ 随安全参数 $n$（如量子态的长度或协议的迭代次数）呈指数级衰减 $\epsilon(n) \\sim \mathcal{O}(e^{-\alpha n})$。
- **不可抵赖性**：合法签名者无法否认其签发的消息。在量子框架下，通过量子态分发和经典/量子信道的交叉验证架构，签名者抵赖其签名行为的发生概率同样受到物理定律的严格限制，趋近于零。因此，量子数字签名被证明能够在甚至存在量子信道噪声和攻防博弈的环境下，提供绝对的无条件安全。

### Reference answer

线性组合酉算符（LCU）是量子算法设计尤其是量子化学模拟中的核心技术。以下从宏观原理、时间复杂度对比、量子加速来源以及代码实现四个方面进行详细解答。

1. 宏观原理
LCU方法的核心思想是将一个一般性的、可能非酉的算符（如分子哈密顿量 H = Σ c_j U_j），通过引入辅助量子比特，嵌入到一个更大的酉演化操作中。具体而言，首先通过归一化因子 λ = Σ |c_j| 对系数进行缩放。然后制备一个辅助寄存器状态 |ψ⟩ = Σ (√(c_j/λ)) |j⟩。接着，根据辅助寄存器的状态对目标系统受控地执行对应的酉操作 U_j，即执行算符 W = Σ |j⟩⟨j| ⊗ U_j。此时，如果忽略辅助寄存器或者通过特定测量将其解纠缠，目标系统有效经历的演化即为 H/λ。在现代量子信号处理（QSP）或量子奇异值变换（QSVT）框架下，LCU常被封装为块编码，即构造一个更大的酉矩阵 U，使得 U 的左上角子矩阵恰好等于 H/λ，从而可以利用多项式变换对哈密顿量进行高精度操作。

2. 时间复杂度对比
在经典计算化学（如全组态相互作用 FCI）中，精确求解多体薛定谔方程需要对维度随粒子数呈指数级增长的哈密顿量矩阵进行对角化。对于 n 个量子比特，希尔伯特空间维度为 N=2^n，经典对角化的时间复杂度至少为 O(N^3) = O(2^{3n})。
而基于LCU的量子模拟算法（如结合Qubitization技术），其时间复杂度与希尔伯特空间的维数无关。模拟复杂度主要由归一化因子 λ 和演化时间 t 决定，复杂度通常为 O(λ t + log(1/ε)) 或 O(λ (t + log(1/ε)))。由于 λ 通常随系统规模仅呈多项式增长，量子算法实现了对经典最优算法的指数级加速。

3. 量子加速来源
这种惊人的指数级加速主要来源于三个方面：
(1) 态叠加的指数级数据压缩：n个量子比特可以同时编码和操作2^n个概率幅，无需像经典算法那样在内存中显式存储指数级大小的向量。
(2) 幺正演化的天然并行性：对于张量积形式的Pauli串 U_j，量子计算机可以在常数或多项式时间内直接对纠缠态进行全局线性变换。
(3) 对数精度的多项式变换：借助于量子傅里叶变换或量子信号处理，量子算法可以将依赖于精度的多项式级开销 O(poly(1/ε)) 压缩为对数开销 O(log(1/ε))，这是经典数值积分难以企及的。

4. 数学推导与isQ代码实现
以哈密顿量 H = 0.6 I + 0.8 Z 为例，归一化因子 λ = 0.6 + 0.8 = 1.4。
我们需要在辅助比特上制备状态 √(0.6/1.4)|0⟩ + √(0.8/1.4)|1⟩。
设旋转角 θ 满足 cos(θ/2) = √(0.6/1.4)，解得 θ ≈ 1.714 rad。
然后执行控制操作：当辅助比特为0时作用 I 门，为1时作用 Z 门。

以下是使用isQ语言实现的Block-Encoding代码框架：

import std;

qbit anc[1];
qbit sys[1];

// 定义哈密顿量各项对应的酉门
// U0 = I
// U1 = Z

procedure main() {
    // 初始化目标系统，假设处于叠加态以展示非平凡演化
    H(sys[0]);

    // 第一步：在辅助比特上制备概率幅与哈密顿量系数成比例的状态
    // cos(θ/2) = sqrt(0.6/1.4), θ ≈ 1.714
    Ry(1.714, anc[0]);

    // 第二步：受控执行酉算符序列
    // 当anc为|0>时，执行U0=I，由于是恒等操作，无需实际加门
    // 当anc为|1>时，执行U1=Z
    ctrl @[anc[0]] Z(sys[0]);

    // 此时，整个系统处于纠缠态
    // 1.4 * (|0><0| ⊗ I + |1><1| ⊗ Z) |anc>|sys>
    // 这就完成了 H/1.4 的 Block-Encoding。
    // 若需继续进行QSP变换，可在此处添加辅助比特上的单比特旋转与多次LCU调用。
    
    // （可选）如果仅需提取状态，可以通过逆变换解除纠缠，并测量辅助比特
    Ry(-1.714, anc[0]);
    
    // 测量辅助比特，若结果为0，则目标系统成功应用了哈密顿量 H
    int r = M(anc[0]);
    if (r == 0) {
        // 目标系统现在包含了H作用的精确结果
    }
}

### Reference answer

量子化学模拟的核心目标是求解分子的静态薛定谔方程，从而获取分子的基态能量、激发态能量以及化学反应的动力学过程。在经典计算中，多电子体系的波函数存在于一个维数随电子数呈指数级增长的希尔伯特空间中。例如，对于包含 $N$ 个自旋轨道的体系，其波函数的维度最高可达 $2^N$。使用经典计算机进行全组态相互作用（FCI）精确求解的时间复杂度是指数级的，即 $O(e^N)$。这意味着当模拟稍大一点的分子（如包含50个电子的分子）时，即便使用最强大的超级计算机，也会因内存和计算时间的指数爆炸而无法胜任。

量子计算机模拟分子电子结构的宏观原理则完全不同。它利用量子比特来直接映射电子的轨道状态。例如，我们可以使用Jordan-Wigner或Bravyi-Kitaev变换，将费米子的产生和湮灭算符映射为量子比特上的泡利算符串。这样，分子的哈密顿量就被转化为量子比特的哈密顿量。随后，我们在量子处理器上制备一个包含多个量子比特纠缠的试探波函数，并通过控制量子门的演化来模拟分子中电子的相互作用，最后通过测量得到系统的能量期望值。

在时间复杂度对比上，量子计算具有质的飞跃。利用著名的量子相位估计算法（QPE），如果我们能够制备出与基态有足够大重叠的初始态，量子计算机可以在多项式时间 $O(Poly(N))$ 内精确提取出分子的基态能量。针对目前NISQ（含噪声中等规模量子）时代的变分量子本征求解器（VQE）算法，其量子态制备和测量的复杂度通常也与系统的多项式缩放相关，从而打破了经典计算机的指数壁。

这种强大的量子加速根本物理来源主要归结为以下三点：
1. 指数级的态空间映射：$N$ 个量子比特能够自然地张成 $2^N$ 维的希尔伯特空间。量子计算机不需要像经典计算机那样遍历或存储这 $2^N$ 个复数，而是直接通过操控量子态的叠加来并行处理庞大的状态空间。
2. 量子纠缠的自然表达：分子的电子结构中充满了强关联效应，特别是在过渡金属络合物或化学键断裂的过程中。这些效应本质上是多体量子纠缠。经典计算机极难高效表示这种复杂的纠缠态，而量子计算机本身的工作基础就是纠缠态，能够以极其紧凑的物理资源真实反映多电子之间的相互作用。
3. 量子干涉效应：在如QPE的量子算法中，通过精巧设计的量子线路，系统能够使代表基态的相位信息通过干涉相互叠加放大，而其他激发态的信息则发生相消干涉。这使得我们能够以极高的概率从巨大的状态空间中精准提取出所需的化学特征值，从而实现超越经典图灵机的计算加速。

### Reference answer

在量子化学模拟中，化学精度（约 1.6 mHa）是预测化学反应速率和热力学性质的关键阈值。然而，当前处于 NISQ（含噪声中等规模量子）时代的量子硬件受限于极短的退相干时间和较高的量子门错误率，使得我们在实际应用中达到化学精度变得异常困难。这些物理局限性对量子资源的影响可以从以下几个维度进行深入剖析：

首先是退相干时间的严格限制。量子比特极其脆弱，容易与环境发生耦合而失去量子叠加态。表征退相干的关键指标是弛豫时间（T1）和失相时间（T2）。在当前的硬件平台（如超导量子计算机）中，T1 和 T2 通常在微秒到百微秒量级。这意味着量子算法的整个运行时间必须被限制在这个时间窗口内。如果运行时间超过相干时间，量子态的信息就会因噪声被完全洗刷掉，导致测量结果退化为经典的随机噪声。因此，任何量子化学算法的电路深度（即执行量子门的总层数）都有着严格的上限，这直接限制了算法能够模拟的分子大小和演化时间。

其次是量子门错误率带来的累积误差。目前硬件上的单比特门保真度通常在 99.9% 左右，而双比特门（如 CNOT）的保真度往往在 99.0% 到 99.5% 之间。在量子化学算法中，无论是变分量子特征求解器（VQE）还是量子相位估计（QPE），都需要进行大量的纠缠操作。例如，在 QPE 算法中，为了获得高精度的分子基态能量，需要进行多次受控酉算符（$e^{-iHt}$）的级联操作，这会导致电路深度呈指数级增长。假设构建的模拟电路包含 1000 个双比特门，即使每个双比特门的错误率仅为 1%，整个电路的累积错误率也会使得最终正确结果的概率降至接近于零，远远无法满足 1.6 mHa 的高精度要求。而对于分子轨道数较多的复杂分子，所需的门数量往往远超这个数值。

最后，这些物理局限极大地膨胀了实际的量子资源消耗。由于 NISQ 设备无法直接运行深度足以达到化学精度的浅层电路，我们必须转向容错量子计算（FTQC）。在容错架构下，为了抵抗退相干和门错误，必须使用量子纠错码（如表面码）。将逻辑量子比特编码到物理量子比特上的过程需要巨大的冗余。当前研究表明，在表面码架构下，若要容错地模拟具有实用价值的分子（如工业化固氮催化剂或复杂药物分子）并达到化学精度，物理量子比特的错误率必须降到 $10^{-4}$ 甚至更低，且所需的物理量子比特数量可能高达数百万乃至上千万个。同时，为了维持逻辑门的保真度，逻辑电路的深度将进一步扩大，这又要求物理硬件具备极高的操作时钟频率和极长的系统级相干时间。

综上所述，退相干和门错误率不仅是当前硬件层面的性能瓶颈，更是决定我们在量子化学计算中需要投入多少量子资源的底层物理标尺。突破这些局限，既依赖于底层物理硬件工艺的提升，也有待于量子纠错理论和耐噪声量子算法的双重演进。

1. **Trotter-Suzuki分解的误差与特点**
Trotter方法通过将总演化时间 $t$ 分割为 $r$ 个小段 $\Delta t = t/r$，并对指数算符进行乘积展开（如 $e^{-iHt} \approx (e^{-ih_1 \Delta t} e^{-ih_2 \Delta t} \dots)^r$）。
- **优点**：电路构造非常直观。在NISQ（含噪中等规模量子）时代，由于它可以利用化学哈密顿量中泡利算符的局部性及天然分块对角化特性，往往具有较小的电路常数开销，且能十分自然地与变分量子特征求解器（VQE）结合。
- **缺点**：误差来源主要是Baker-Campbell-Hausdorff (BCH) 公式中的高阶对易子项。一阶Trotter误差正比于 $O(L^2 \max||[h_j, h_k]|| \Delta t^2)$，随着系统规模 $L$ 增大或演化时间 $t$ 变长，为压制误差所需的门数量呈多项式甚至指数级爆炸。

2. **Qubitization / QSP 的误差与特点**
Qubitization将哈密顿量编码在一个更大的酉矩阵的子空间中，利用量子信号处理进行严格的特征值相移。
- **优点**：具有最优的渐近时间复杂度 $O(t)$，且演化误差不依赖于哈密顿量各项之间的对易关系。在大型容错量子计算机上，对强关联体系（如铁硫簇等过渡金属配合物）进行长时间高精度演化时，它是唯一可行的方法。

**适用场景对比**：
如果是在NISQ时代探索短时间和中小分子体系，或者进行低阶变分求解，Trotter分解是首选；如果是未来在容错设备上模拟复杂化学动力学、费米子全配置相互作用（FCI）的长绝热演化，则必须采用Qubitization方法。

在量子化学模拟中，体系的哈密顿量通常可以表示为若干局部算符之和，即 $H = \sum_k h_k$。由于这些局部算符 $h_k$ 通常是不对易的，指数算符的乘积并不等于指数和的算符，即 $e^{-i(A+B)t} \neq e^{-iAt}e^{-iBt}$。Trotter-Suzuki分解正是为了解决这一问题。一阶Trotter公式通过将总演化时间 $t$ 分割为 $n$ 个极小的片段 $\Delta t = t/n$，利用 Lie Product Formula 进行近似：
$e^{-iHt} \approx \left( \prod_k e^{-i h_k \Delta t} \right)^n$
当 $n \to \infty$ 时，该近似将严格等于实际的时间演化。在量子电路中，这意味着我们需要将每一项 $h_k$ 对应的幺正演化门序列重复执行 $n$ 次。

以下是针对化学哈密顿量 $H = 0.5Z_0 + 0.3Z_0Z_1 + 0.2X_0X_1$ 的完整isQ代码实现，其中包含了10个Trotter步长的演化过程：

```isQ
import std;

// 全局声明2个量子比特用于编码化学基态
qbit q[2];

// 程序入口
procedure main() {
    // 设定总演化时间 t
    double t = 3.14;
    // 设定Trotter步数 n，步数越大截断误差越小
    int n = 10;
    // 计算单步演化时间 dt
    double dt = t / n;

    // 初始化量子态，这里将两个比特置于均等叠加态，模拟一般初始态
    H(q[0]);
    H(q[1]);

    // 执行 n 次 Trotter 步长迭代
    for i in 0:n {
        // === 演化第一项：0.5 * Z0 ===
        // 对应的幺正算符为 e^(-i * 0.5 * Z0 * dt)
        // 在量子计算中，绕Z轴旋转 theta 角度的门为 Rz(theta)
        // 因为 Rz(theta) = e^(-i * theta/2 * Z)，所以令 theta = 2 * 0.5 * dt
        Rz(2.0 * 0.5 * dt, q[0]);

        // === 演化第二项：0.3 * Z0Z1 ===
        // 对应的幺正算符为 e^(-i * 0.3 * Z0Z1 * dt)
        // Z0Z1 属于双量子比特纠缠项，可通过 CNOT-Rz-CNOT 结构来实现
        CNOT(q[0], q[1]);
        // 作用在目标比特上的旋转角为 2 * 0.3 * dt
        Rz(2.0 * 0.3 * dt, q[1]);
        CNOT(q[0], q[1]);

        // === 演化第三项：0.2 * X0X1 ===
        // 对应的幺正算符为 e^(-i * 0.2 * X0X1 * dt)
        // X 门与 Z 门互为相似变换，H Z H = X
        // 因此在首尾施加 Hadamard 门即可将 Z0Z1 的演化电路转换为 X0X1 的演化电路
        H(q[0]);
        H(q[1]);
        
        // 复用相同的 CNOT-Rz-CNOT 结构
        CNOT(q[0], q[1]);
        // 旋转角修改为对应的 2 * 0.2 * dt
        Rz(2.0 * 0.2 * dt, q[1]);
        CNOT(q[0], q[1]);
        
        // 恢复基矢
        H(q[0]);
        H(q[1]);
    }

    // 对演化后的量子态进行测量，以获取体系化学态的概率分布
    int r0 = M(q[0]);
    int r1 = M(q[1]);
    
    // 打印测量结果
    print r0;
    print r1;
}
```

### Prompt

在量子化学计算中，“化学精度”（通常指能量误差小于1 kcal/mol 或约1.6 mHa）是评估化学反应能否准确预测的关键阈值。请从计算复杂度和物理原理的角度分析，为什么经典计算机在模拟复杂分子（尤其是强关联体系）达到化学精度时面临巨大瓶颈？相比于经典算法，量子算法（如量子相位估计）在求解分子基态能量以达到化学精度时，其时间复杂度有何根本性优势？请详细阐述这种量子加速的底层物理来源。

### Reference answer

在量子化学中，达到“化学精度”意味着计算出的系统能量与真实物理值的误差必须控制在约1.6毫哈特里以内，这是可靠预测化学反应路径、反应速率和催化剂效率的前提。

**经典计算的瓶颈与计算复杂度**： 
经典计算机面临的核心瓶颈在于多电子体系波函数的指数级维数爆炸。对于一个包含N个自旋轨道的分子体系，其希尔伯特空间的维度为2^N。为了在经典计算机上达到化学精度，尤其对于过渡金属配合物或发生化学键断裂的“强关联体系”，通常需要采用全组态相互作用等高阶方法。FCI的计算时间复杂度随系统规模呈指数级增长，约为O(exp(N))。即使是最先进的经典近似算法（如CCSD(T)），其时间复杂度也是高阶多项式的（约O(N^7)），且在处理强关联动态时往往无法收敛或达不到化学精度。

**量子算法的时间复杂度优势**： 
量子计算为解决这一难题提供了根本性的复杂度降低。使用量子相位估计（QPE）等量子算法来求解分子的基态能量，其时间复杂度可以降低到多项式级别，通常标度为O(poly(N, 1/ε))，其中ε为所需的能量精度。这意味着，随着分子大小的增加，量子计算机为了达到化学精度所需的计算资源（时间）只按多项式增长，而经典FCI算法则是指数级飙升。这种从O(exp(N))到O(poly(N))的跨越，是实现大分子高精度模拟的关键。

**量子加速的底层物理来源**： 
这种惊人的计算加速主要源于量子力学的三个核心特性：
1. **量子态的指数级并行表示**：由n个量子比特构成的量子寄存器可以自然地处于2^n维希尔伯特空间的叠加态上。这意味着量子计算机不需要像经典计算机那样消耗指数级的内存来存储波函数，系统规模每增加一个轨道，仅需增加一个量子比特即可完美编码其状态。
2. **量子纠缠匹配多体关联**：在强关联体系中，电子之间的相互作用高度复杂。量子计算机通过量子门操作产生的纠缠态，能够天然、高效地捕捉和表示多体电子之间的复杂关联效应，而这是经典张量网络难以高效压缩的。
3. **量子干涉与相位提取**：QPE算法利用了量子傅里叶变换的强大能力。通过对演化算符施加可控的量子操作，量子系统能够利用量子干涉效应，极其迅速地将编码在量子态相位中的特征能量值（基态能量）提取出来，其提取精度随演化时间呈指数级收敛，从而以极高的效率达到化学精度的要求。

### Prompt

量子计算在药物发现领域的一个核心应用是模拟药物分子的电子结构（例如使用VQE算法计算基态能量），以预测其化学性质和亲和力。然而，目前我们仍处于NISQ（含噪声的中等规模量子）时代。请问当前的量子硬件在执行此类药物发现任务时，面临哪些主要的物理局限性？特别是退相干和门错误率，是如何具体影响药物分子模拟的精度的？

### Reference answer

在当前的NISQ时代，利用量子计算机进行药物发现面临着严峻的硬件物理局限性。真实的药物分子通常包含大量电子，对应着庞大的希尔伯特空间和极其复杂的分子哈密顿量。在将这些哈密顿量映射到量子比特（如Jordan-Wigner变换）并使用变分量子本征求解器（VQE）等算法求解时，会遇到以下几方面的严重限制：

首先是**门错误率**的累积效应。在目前的超导或离子阱量子计算机上，单比特门错误率通常在0.1%左右，而两比特门（如CNOT）的错误率往往高达1%甚至更高。对于药物分子模拟，VQE线路需要大量的两比特纠缠门来构建包含多体相互作用的Ansatz（试探波函数）。如果一个药物分子的模拟需要数百个CNOT门，即使每个门有99%的保真度，整体线路的成功率也会呈指数级衰减。这种累积的系统误差会严重扭曲分子能量景观，导致经典优化器无法收敛到真实的基态能量，使得计算出的药物亲和力完全失去化学参考价值（通常要求化学精度在1.6 milli-Hartree以内）。

其次是**退相干时间（T1和T2）**的限制。量子比特是极其脆弱的，量子态很容易与环境发生纠缠而丢失相位信息。在药物分子模拟中，由于分子体系庞大，需要较深的量子线路来制备和测量分子态。如果整个量子线路的执行时间超过了量子比特的退相干时间，计算结果就会退化为完全的随机噪声。例如，复杂的药物分子可能需要上千个量子门，这在当前硬件的相干时间内根本无法执行完毕，导致在测量阶段无法提取出有效的量子干涉信息，算出的能量值往往远高于真实的基态能量。

最后是**量子比特连通性与物理比特数**的限制。药物分子中经常存在远距离的电子关联效应（如非共价相互作用、大环结构等）。这要求硬件具备远距离的量子比特连通性。在当前局部连通的硬件拓扑（如超导量子芯片的二维网格）中，引入非相邻比特间的相互作用需要插入大量的SWAP门。每个SWAP门由3个CNOT门组成，这不仅极大地加深了线路，还成倍地放大了上述的门错误率和退相干问题。

综上所述，在NISQ设备上，退相干和门错误率严重限制了可精确模拟的药物分子尺寸和模拟精度。在量子纠错（QEC）技术成熟之前，我们只能结合经典计算（如混合量子-经典算法），并大量依赖量子错误缓解技术来尝试突破这些物理瓶颈，处理极小规模的药物片段。

### Prompt

在量子化学的量子线路设计中，Jordan-Wigner变换是一种将费米子产生和湮灭算符映射到泡利算符的标准方法，但它会引入长程的Pauli-Z门串，导致量子门数量呈线性增长。请问针对Jordan-Wigner变换的非局域性缺陷，有哪些重要的改进版本或变体映射方法？请以Bravyi-Kitaev变换为例，详细阐述它是如何平衡占据数信息和奇偶校验信息，从而将门复杂度降低到对数级别的？最后，请提供一个使用isQ语言的代码示例，展示如何实现某个简化映射后的哈密顿量项（如XYYX类型）的时间演化。

### Reference answer

Jordan-Wigner (JW) 变换在处理远距离轨道的电子算符时，需要引入包含大量 Pauli-Z (Z) 门的 Z 串来保证费米子的反对易关系。对于具有 N 个自旋轨道的系统，JW 映射下的门复杂度为 O(N)。为了克服这种由于非局域性带来的高昂量子门开销，研究者们提出了几种重要的优化变体：

1. Parity（宇称）变换：这种变体不再直接编码占据数，而是编码直到位置 i 的电子总数的奇偶性。虽然它减少了某些奇偶校验操作的成本，但更新远端比特仍需要长程门串。
2. Bravyi-Kitaev (BK) 变换：这是目前应用最广泛的改进变体之一。它通过引入二叉树数据结构，将一部分量子比特用于存储占据数信息，另一部分用于存储宇称信息。这种混合编码策略打破了 JW 变换中的串行依赖。
3. Bravyi-Kitaev Superfast 变换：专门针对图状费米子结构（如晶格模型）设计，通过边缘态编码，进一步在某些特定拓扑结构下将复杂度降至 O(1)。

以 Bravyi-Kitaev 变换为例，其核心数学思想在于对索引 i 进行二进制分解：
<thiche>
\text{在BK映射中，索引 } i \text{ 的二进制表示被分散存储。对于算符 } a_i \text{，其对应的Pauli串长度取决于} i \text{ 的更新集和奇偶集。更新集的体积近似为 } O(\log_2 N) \text{。因此，相比于JW映射中：}
a^{\dagger}_j = \frac{1}{2}(X_j - iY_j) \otimes \bigotimes_{k=0}^{j-1} Z_k
\text{BK映射将中间长长的 } Z \text{ 串替换为长度仅为 } O(\log N) \text{ 的Pauli算符张量积。}
</thiche>
通过这种对数级的空间划分，BK 变换成功将非局域操作的深度从 O(N) 压缩至 O(log N)，极大提升了变分量子本征求解器（VQE）等算法在近期量子设备上的运行效率。

<thiche>
import std;

qbit q[4];

// 定义应用特定哈密顿量项X0 Y1 Y2 X3的指数演化门
// 输入参数：演化角度theta
gate apply_xyyx_evolution(double theta) {
    // 将Y1和Y2转换到X基或Z基，以便通过CNOT级联计算奇偶性
    // Y = H S Z S H 或者利用特征基变换
    // 这里使用等效的基变换：Y = S H Z H S_dag
    // 为了简化线路，我们直接对目标比特进行基变换
    Rx(1.5707963, q[0]); // pi/2
    Ry(1.5707963, q[1]); // pi/2
    Ry(1.5707963, q[2]); // pi/2
    Rx(-1.5707963, q[3]); // -pi/2

    // 利用CNOT链计算多比特间的奇偶校验，将多体相互作用压缩到目标比特q[3]上
    CNOT(q[0], q[1]);
    CNOT(q[1], q[2]);
    CNOT(q[2], q[3]);

    // 在目标比特上应用绕Z轴的旋转，实现演化角度的累加
    Rz(theta, q[3]);

    // 逆转CNOT链以恢复原状态
    CNOT(q[2], q[3]);
    CNOT(q[1], q[2]);
    CNOT(q[0], q[1]);

    // 逆转之前的基变换操作
    Rx(1.5707963, q[3]);
    Ry(-1.5707963, q[2]);
    Ry(-1.5707963, q[1]);
    Rx(-1.5707963, q[0]);
}

procedure main() {

    for i in 0:4 {
        H(q[i]);
    }

    // 应用映射后哈密顿量项的时间演化
    apply_xyyx_evolution(0.5);
}

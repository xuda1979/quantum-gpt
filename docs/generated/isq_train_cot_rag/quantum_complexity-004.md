### Reference answer

BQP（Bounded-Error Quantum Polynomial Time，有界错误量子多项式时间）是量子计算复杂性理论中最基础且最重要的复杂性类之一，它定义了量子计算机在多项式时间内能够有效解决且错误率不超过1/3的判定问题集合。这个概念的确立是计算复杂性理论从经典向量子跨越的里程碑。

**历史背景与核心奠基人**
在20世纪80年代，理查德·费曼和戴维·多伊奇分别提出了量子计算的基本概念和量子图灵机（QTM）的初步物理设想。然而，直到90年代初，理论计算机科学界仍然缺乏一个严格的数学框架来界定量子算法的计算复杂度。经典计算中有著名的BPP（有界错误概率多项式时间）类，但量子计算涉及复杂的概率幅叠加与干涉，如何定义一个合理的“量子多项式时间”成为亟待解决的理论难题。

1993年，Ethan Bernstein和Umesh Vazirani在他们的开创性论文《Quantum Complexity Theory》中，对量子图灵机进行了严格的数学形式化，并在此基础上**首次正式提出了BQP复杂性类**。他们不仅给出了BQP的精确定义，还证明了一个里程碑式的结论：量子图灵机的计算能力完全等价于多项式规模的量子线路（量子电路模型）。这一发现不仅确立了BQP作为量子复杂性理论核心的地位，还证明了BQP包含在经典复杂性类PSPACE中（BQP ⊆ PSPACE），从而从理论上划定了量子计算机在多项式时间内的计算能力上限。

**后续里程碑与地位的巩固**
尽管Bernstein和Vazirani定义了BQP，但BQP是否真的比经典计算机对应的BPP更强大，在提出之初仍缺乏强有力的算法证据。

1. 1994年：Peter Shor与Shor算法
这是巩固BQP地位的最重要的里程碑。Peter Shor提出了大整数分解和离散对数的量子多项式时间算法，证明了此类被广泛认为对经典计算机极其困难（属于NP但不属于P的候选问题）的问题实际上属于BQP。Shor算法表明BQP极有可能严格大于BPP，彻底引爆了学界对量子计算的兴趣。

2. 1996年：Lov Grover与Grover算法
Grover提出了非结构化数据库搜索的量子算法，提供了相对于经典暴力搜索的平方级加速。虽然它不像Shor算法那样提供指数级加速，但它进一步丰富了BQP复杂性类的算法下界，展示了量子计算在更广泛问题上的计算优势。

总结而言，BQP复杂性类是由Ethan Bernstein和Umesh Vazirani在探讨量子图灵机复杂度界限时正式提出的，随后在Peter Shor、Lov Grover等人的里程碑式算法的推动下，成为了衡量量子计算机计算能力的黄金标准，并深刻影响了现代密码学和计算理论的发展。

### 1. 陷阱的根源：将“相对化屏障”等同于“绝对真理”
该误解的核心在于没有正确理解“相对化”的数学意义。BBBV定理确实严密地证明了存在一个oracle A，使得相对于该oracle，有 \( NP^A \not\subseteq BQP^A \)。

这个结论告诉我们：在只能将问题作为“黑盒”进行查询的计算模型中，量子算法无法突破平方级加速的桎梏。这意味着，如果我们把一个NP问题纯粹当作一个盲盒（只给输入，看输出），量子计算机依然需要 \( O(2^{n/2}) \) 的指数级时间。

### 2. 现实NP问题不是黑盒
BBBV定理的成立强烈依赖于“黑盒查询模型”。在黑盒模型下，算法对问题的内在结构一无所知。但在现实世界中，像3-SAT或旅行商问题这样的NP完全问题，并非毫无结构的黑盒函数。它们具有极其丰富的逻辑约束和组合结构。

### 3. 历史的先例：非相对化证明的存在
在复杂度理论中，存在大量“相对化预言失效”的例子。最著名的就是 \( IP = PSPACE \) 的证明。在此之前，人们也通过构造oracle证明了在某些相对化世界里 \( IP \neq PSPACE \)，但这最终并没有阻止现实世界中 \( IP = PSPACE \) 的绝对成立。这是因为 \( IP = PSPACE \) 的证明使用了高度非相对化的技术（如算术化，将布尔公式转化为多元多项式），这些技术深刻利用了公式的具体结构，而不仅仅是将其作为黑盒查询。

同理，尽管存在BBBV定理的oracle分离，我们依然不能排除未来有人利用非相对化技术，发掘出NP完全问题的深层代数结构，从而证明 \( NP \subseteq BQP \)。

**错误说法**认为“Oracle分离直接宣告了量子计算在解决NP问题上的死刑”。
**正确理解**是：BBBV定理只是给出了一项“技术限制”，它告诉我们量子计算机在解决NP问题时，不可能仅仅依靠“量子并行的暴力猜测+黑盒检测”这种方式来获得指数加速。要想攻克NP问题，未来的量子算法必须能够“看透”并利用问题本身的非平凡数学结构。因此，\( NP \) 与 \( BQP \) 的绝对包含关系至今仍是计算理论界的未解之谜。

### Reference answer

随机电路采样（Random Circuit Sampling, 简称 RCS）是量子计算领域中一种用于证明“量子优势”（或称量子霸权）的基准测试任务。它的核心过程是：在量子计算机上运行一个由随机选取的量子门构成的深度电路，然后对输出的量子态进行多次测量，采样得到一系列由0和1组成的比特串。

具体而言，随机电路的构造通常包括交替层的随机单量子比特门和双量子比特门。假设我们有 $n$ 个量子比特，初态为 $|0\rangle^{\otimes n}$，经过随机量子电路演化后的末态可以表示为：
$$ |\psi\rangle = U |0\rangle^{\otimes n} $$
其中 $U$ 是一个随机酉矩阵。由于量子测量的概率特性，测量末态 $|\psi\rangle$ 得到某一特定比特串 $x \in \{0,1\}^n$ 的概率为 $P(x) = |\langle x|\psi\rangle|^2$。RCS 的任务就是不断地执行这个电路并测量，以生成符合概率分布 $P(x)$ 的样本集合。

为了让你直观理解，下面展示一段生成两层随机电路并测量3个量子比特的 isQ 代码示例。我们用参数化的旋转门 $R_x(\theta)$ 和 $R_y(\theta)$ 模拟随机的单量子比特门，并插入 CZ 门作为双比特纠缠门：

```isq
import std;

qbit q[3];

procedure main() {
    // 初始化态默认为 |000>

    // 第一层：随机单量子比特门
    Rx(1.23, q[0]);
    Ry(4.56, q[1]);
    Rx(2.34, q[2]);

    // 第二层：双量子比特门 (通常构成纠缠)
    CZ(q[0], q[1]);
    CZ(q[1], q[2]);

    // 第三层：再叠加一层随机单量子比特门
    Ry(0.78, q[0]);
    Rz(3.14, q[1]);
    Rx(1.01, q[2]);

    // 测量所有量子比特，完成采样
    M(q[0]);
    M(q[1]);
    M(q[2]);
}
```

**为什么 RCS 是量子优势的有力证据？**

1. **经典计算复杂性理论瓶颈**：
随着量子比特数量 $n$ 的增加，描述整个量子系统状态所需的希尔伯特空间维度呈指数级增长（$2^n$）。对于一个具有足够深度和连通性的随机电路，经典计算机要想精确计算其输出分布 $P(x)$ 或从中进行精确采样，将需要消耗极其庞大的计算资源。理论计算机科学中的“交叉熵保真度”被用于验证采样结果。从复杂性理论的角度（如基于“反对称延展假设”，Anticoncentration conjecture），经典计算机在合理的时间内模拟 RCS 并达到相同的保真度被普遍认为是极度困难的。如果经典算法能轻易模拟 RCS，将导致计算复杂性层级的坍塌。

2. **波特-托马斯分布**：
在足够深度的随机电路作用下，输出各个比特串的概率分布 $P(x)$ 会呈现出一种特殊的统计分布——波特-托马斯分布，这是高维随机酉矩阵哈-特征的特征。这意味着绝大多数的输出比特串出现的概率极低，只有极少数状态的概率相对较高。这种分布使得经典算法（如马尔可夫链蒙特卡洛方法）很难有效地猜测出高概率的采样结果。

3. **易于验证的交叉熵基准**：
虽然经典计算机无法完全模拟大规模的随机电路，但我们可以通过“线性交叉熵保真度”来验证量子计算机的输出是否真的执行了这些复杂的量子计算。具体来说，我们可以先在经典计算机上计算一个小规模或浅层电路的某些特定输出概率，然后检查量子计算机采样出的结果是否偏向于这些概率较高的状态。如果量子计算机的采样结果在统计上显著优于经典随机猜测，这就强有力地证明了量子处理器确实在进行真实的、经典计算机难以企及的量子演化。

综上所述，谷歌在2019年著名的“悬铃木”实验就是基于 53 个量子比特的随机电路采样。由于经典计算机需要花费数千年才能完成同等的采样任务，这标志着人类首次在实验上实现了“量子优势”。RCS 因此成为了验证现代嘈杂中型量子（NISQ）设备计算能力的黄金标准。

Clifford电路的经典可高效模拟性是量子计算复杂度理论中的一个核心结论，由Gottesman-Knill定理严格确立。该定理表明，尽管Clifford电路能够产生高度纠缠的量子态（如Bell态和GHZ态），但由于其动力学被限制在Pauli群内，因此可以被经典计算机在多项式时间内模拟。

### 1. 数学形式化与稳定子体系
定义在 $n$ 个量子比特上的Pauli群 $\mathcal{P}_n$ 包含所有形如 $P = i^c \bigotimes_{j=1}^n P_j$ 的张量积，其中 $P_j \in \{I, X, Y, Z\}$ 且 $c \in \{0, 1, 2, 3\}$。

对于任意纯态 $|\psi\rangle$，其对应的稳定子群定义为 $\mathcal{S}(|\psi\rangle) = \{ g \in \mathcal{P}_n \mid g|\psi\rangle = |\psi\rangle \}$。如果 $|\psi\rangle$ 是一个稳定子态，则群 $\mathcal{S}$ 可以由 $n$ 个独立的、两两对易的Pauli字符串 $g_1, g_2, \dots, g_n$ 生成。因此，在经典计算机上，我们无需记录 $2^n$ 维的状态向量，只需维护这 $n$ 个生成元即可完整描述该量子态。

为了进一步实现高效计算，我们将Pauli字符串映射到二元域 $\mathbb{F}_2^{2n}$ 上的辛向量。忽略全局相位，Pauli算子 $P = \bigotimes_{j=1}^n (X_j^{x_j} Z_j^{z_j})$ 可以表示为长度为 $2n$ 的二进制行向量：
$$ v = (x_1, x_2, \dots, x_n \mid z_1, z_2, \dots, z_n) $$
两个Pauli算子 $u$ 和 $v$ 对易的充要条件是它们的辛内积为零：
$$ u \cdot v = \sum_{j=1}^n (u_{x_j} v_{z_j} + u_{z_j} v_{x_j}) \equiv 0 \pmod 2 $$
由此，稳定子态可以由一个 $n \times 2n$ 的二进制矩阵 $S$ 表示，其行向量相互正交（即 $S \Lambda S^T = 0$，其中 $\Lambda$ 为辛标准型矩阵）。

### 2. 酉演化的模拟
Clifford电路由Clifford门（如H, S, CNOT）构成，其数学定义为满足 $C \mathcal{P}_n C^\dagger = \mathcal{P}_n$ 的酉算子 $C$。
当系统经历酉演化 $|\psi'\rangle = C |\psi\rangle$ 时，稳定子生成元相应地变为：
$$ g_i \to g_i' = C g_i C^\dagger $$
由于 $g_i'$ 仍然是Pauli群中的元素，在二进制矩阵表示下，这等价于对矩阵 $S$ 的每一行进行二进制加法操作或行列置换。例如，CNOT门会将控制位和目标位的X分量相加。这种更新操作的时间复杂度为 $O(n)$，因此维持一个包含 $n$ 个生成元的状态所需的时间复杂度仅为 $O(n^2)$。

### 3. 测量过程的模拟
假设我们对第 $k$ 个量子比特在计算基下进行测量，这等价于测量可观测量 $Z_k$（对应二进制向量 $e_{2k}$）。测量过程分为两种情况：

1. **确定性测量**：如果 $Z_k$ 与所有生成元 $g_i$ 对易，即 $Z_k \in \mathcal{S}$ 的中心化子。此时，测量结果 $r \in \{0, 1\}$ 是确定的，状态 $|\psi\rangle$ 是 $+Z_k$ 或 $-Z_k$ 的本征态。若 $Z_k \in \mathcal{S}$，则 $r=0$；若 $-Z_k \in \mathcal{S}$，则 $r=1$。生成元矩阵 $S$ 无需更新。
2. **随机性测量**：如果存在某个生成元 $g_j$ 与 $Z_k$ 反对易，则测量结果是随机的（各为50%概率）。测量后，状态坍缩到对应的本征空间，数学上等价于用 $Z_k$ 替换 $g_j$，并利用行变换确保新的生成元集合仍满足相互对易的条件。这对应于在二进制矩阵中替换一行并进行高斯消元，时间复杂度同样为 $O(n^2)$。

综上所述，状态初始化、门操作和测量均可在经典 $O(n^2)$ 的空间和时间复杂度内完成，从而实现了多项式时间的高效模拟。

### 4. 代码示例

**陷阱辨析与理论纠正：**

1. **计算目标的本质区别（无结构 vs. 强结构）：**
随机电路采样（RCS）的任务是运行一个由随机单比特门和双比特门组成的量子电路，并对其输出进行多次测量，得到一个符合特定概率分布的比特串样本。这个问题被专门设计成“对经典计算机尽可能困难”，因为它毫无规律和结构可言，经典计算机只能被迫通过指数级膨胀的张量网络或状态向量去模拟整个 $2^N$ 的希尔伯特空间。
然而，破解RSA需要的是Shor算法。Shor算法并不是随机的，它高度依赖量子傅里叶变换（QFT）去寻找隐藏在函数中的周期性。这种强大的代数结构在RCS电路中被刻意避开了。用RCS去破解RSA，就像是用一台算力无穷的抛硬币机去解微积分方程，两者在计算复杂性上属于完全不同的维度。

2. **计算复杂性的不可传递性：**
量子计算在RCS上的霸权（属于量子采样问题，如BosonSampling或RCS），并不代表它在解决所有经典难题（如NP问题中的因数分解）上都能展现出同等量级的碾压优势。目前没有理论证明解决RCS问题的能力可以转化为解决质因数分解的能力。

**代码辅助说明：**
为了直观理解，我们可以看下面这段用isQ语言编写的简化的随机电路采样（RCS）结构示例：

```isq
import std;

qbit q[3];

procedure main() {
    // RCS电路通常由随机的单比特门和双比特门交替组成
    // 第一层：制备叠加态
    H(q[0]);
    H(q[1]);
    H(q[2]);

    // 第二层：无规律的随机纠缠操作
    T(q[0]);
    Rx(1.23, q[1]); // 插入随机角度的门，破坏规律性
    CNOT(q[0], q[1]);
    
    T(q[2]);
    Ry(0.71, q[0]);
    CZ(q[1], q[2]);
    
    // 更多随机层...
    
    // 最终测量，得到类似 010, 110 这样看似完全随机的采样结果
    M(q[0]);
    M(q[1]);
    M(q[2]);
}
```

从上述代码可以看出，RCS电路中大量充斥着诸如 `Rx(1.23)` 和 `Ry(0.71)` 这样带有随机参数的非对易量子门。这种“随机性”就像把一台精密的超级计算机变成了一台极其复杂的“量子骰子制造机”。这台机器掷出的骰子面数高达 $2^{50}$ 或更多，经典计算机确实很难模拟这颗复杂骰子的概率分布；但这台骰子机并没有执行解方程、找周期等“逻辑运算”。

**总结：**
RCS实验是验证量子硬件操控性与噪声容忍度的一座里程碑，它证明了量子力学的指数级空间确实能被物理操控。但它绝不是一台通用量子计算机，更不意味着当前的量子优越性可以直接转化为对现有密码学体系的实际威胁。

### Reference answer

在计算复杂性理论的历史中，“相对化”和“神喻分离”是理解不同计算模型能力差异的核心概念。这一概念最早可追溯至1975年Baker、Gill和Solovay的经典论文，他们通过引入“神喻黑盒”证明了P对NP问题在不同的神喻下可以有不同的相对化结果，这意味着任何仅依赖于黑盒查询（即相对化）的证明技术都难以解决P vs NP问题。

当量子计算在20世纪80年代末至90年代初开始兴起时，研究者们面临着一个根本性问题：量子计算机是否真的能比经典计算机更高效地解决某些问题？由于证明绝对的计算能力分离（如证明P ≠ BPP或BPP ≠ BQP）极其困难，科学家们决定采用相对化方法。在这一历史进程中，有两个极其重要的里程碑：
1. **1993年，Ethan Bernstein和Umesh Vazirani的开创性工作**：他们首次在论文中正式定义了量子复杂性类BQP，并提出了一个被称为“递归傅里叶采样”的问题。他们证明了存在一个神喻黑盒，使得量子图灵机可以以多项式时间解决该问题，而任何经典概率图灵机都需要超多项式时间。这是历史上首次在相对化意义下严格证明量子计算相对于经典计算的指数级优势。
2. **1997年，Bennett、Bernstein、Brassard和Vazirani（BBBV定理）**：这四位科学家进一步深化了神喻分离的研究，他们证明了在相对化世界中，虽然量子计算具有强大能力，但它并不能像解决Simon问题或Shor算法那样直接解决NP问题，即存在神喻使得NP不属于BQP。这一结论完美地将BQP定位在P和PSPACE之间，清晰地勾勒出了量子计算的相对化能力边界。

为了直观展示相对化优势是如何在量子算法中产生的，我们可以看**Bernstein-Vazirani算法**。假设存在一个隐藏的比特串 $s \in \{0,1\}^n$，神喻（黑盒）计算函数 $f_s(x) = s \cdot x \pmod 2$。经典确定性或概率算法需要查询该黑盒 $n$ 次才能确定所有的 $n$ 个比特；而量子算法通过巧妙地利用量子叠加和相位干涉，只需查询 **1次** 神喻即可提取全部信息。

从数学原理上看，量子黑盒执行酉变换：
$$U_f |x\rangle |y\rangle = |x\rangle |y \oplus f_s(x)\rangle$$

下面是使用isQ量子编程语言演示Bernstein-Vazirani算法的程序代码，假设隐藏比特串为 $s = 101$，使用3个量子比特作为查询寄存器，1个量子比特作为辅助寄存器：

```isQ
import std;

qbit q[4]; // q[0..2]为查询寄存器, q[3]为辅助寄存器

procedure main() {
    // 初始化辅助位为 |1> 以利用相位反冲效应
    X(q[3]);

    // 对所有量子比特应用Hadamard门，进入等概率叠加态
    for i in 0:4 {
        H(q[i]);
    }

    // --- 调用神喻黑盒 ---
    // 针对隐藏比特串 s=101 构建的神喻
    // 根据比特串的位是否为1，对辅助位执行受控NOT门
    CNOT(q[0], q[3]);
    CNOT(q[2], q[3]);
    // -------------------

    // 再次对查询寄存器应用Hadamard门，引发相位干涉
    for i in 0:3 {
        H(q[i]);
    }

    // 测量查询寄存器，结果必定为隐藏比特串 101
    for i in 0:3 {
        M(q[i]);
    }
}
```

在上述isQ代码中，神喻黑盒表现为对辅助位的受控非门操作。由于初始时查询寄存器处于均匀叠加态，神喻通过相位反冲将函数值 $f_s(x)$ 编码到查询寄存器的相对相位中。随后的第二次Hadamard变换（即量子傅里叶变换的简化形式）将这些相位信息转换为了幅度信息。这种从查询复杂度角度出发利用黑盒进行的指数级分离，正是早期科学家确信量子计算具有革命性潜力的核心历史动因。

在量子计算复杂度理论中，“Clifford电路的经典模拟”是指通过经典多项式时间算法来精确追踪和计算特定受限量子电路的输出概率分布，而完全避免了在指数级增长的希尔伯特空间 $\mathcal{H} = (\mathbb{C}^2)^{\otimes n}$ 中直接演化状态向量。其严谨的学术定义建立在稳定子形式体系与群论之上。

具体而言，设系统由 $n$ 个量子比特组成。首先定义 $n$ 阶 Pauli 群 $\mathcal{P}_n$，它由所有形如 $i^c \sigma_1 \otimes \sigma_2 \otimes \cdots \otimes \sigma_n$ 的张量积构成，其中 $c \in \{0,1,2,3\}$ 为相位因子，$\sigma_j \in \{I, X, Y, Z\}$ 为单比特 Pauli 矩阵。相应的，$n$ 阶 Clifford 群 $\mathcal{C}_n$ 定义为 Pauli 群的正规化子，即满足 $\mathcal{C}_n = \{U \in U(2^n) \mid U \mathcal{P}_n U^\dagger = \mathcal{P}_n\}$ 的酉算子集合。根据群论推导，该群可以仅由 Hadamard 门 (H)、Phase 门 (S) 以及 CNOT 门有限生成。

在稳定子体系中，状态空间并非用复数概率振幅表示，而是由 Pauli 群的一个极大阿贝尔子群（即稳定子群 $\mathcal{S}$）来刻画。对于由 $n$ 个相互对易且独立的 Pauli 算符构成的生成元集合 $\{g_1, g_2, \dots, g_n\}$，若满足 $-I \notin \langle g_1, \dots, g_n \rangle$，则存在唯一的量子态 $|\psi\rangle$，使得对于该子群内的所有算子都有 $g |\psi\rangle = |\psi\rangle$。

这种经典可模拟性的严格数学基石是 **Gottesman-Knill 定理**。该定理证明：如果一个量子电路满足：(1) 初始态为计算基态 $|0\rangle^{\otimes n}$ 或任何稳定子态；(2) 演化过程仅由 Clifford 群中的酉操作构成；(3) 测量是在 Pauli 基上进行的；那么该电路的演化可以被经典计算机在多项式时间内精确模拟，其时间复杂度随量子比特数 $n$ 的增长最多呈二次方 $O(n^2)$（使用标准 Tableau 表示法）或线性 $O(n)$（使用 Aaronson-Gottesman 算法）。

从深层物理机制来看，之所以能实现高效模拟，是因为当 Clifford 门作用于 Pauli 算子时，其共轭作用仅仅诱导了有限域 $\mathbb{F}_2$ 上的辛几何变换。通过将稳定子的生成元映射为 $2n \times 2n$ 的经典二进制矩阵（称为 Tableau），Clifford 门的物理作用被严格同构映射为对经典比特阵列的初等行变换。因此，尽管 Clifford 电路能够以多项式深度生成包含高度纠缠的量子态（如 Bell 态或 GHZ 态），其内在的线性代数结构依然封闭于 Pauli 框架内，这从复杂度理论上反证了：纯粹的 Clifford 演化不足以突破经典计算的 BPP 界限，实现通用量子计算必须引入非 Clifford 门（如 T 门）以打破稳定子的封闭性。

### Reference answer

随机电路采样不仅是证明量子优越性的工具，它本质上是对量子纠缠和希尔伯特空间复杂性的深度探索，与量子计算的多个核心领域有着紧密且深刻的跨领域关联：

1. **与多体物理和哈密顿量模拟的关联**：随机电路的演化在数学上等价于研究高维多体系统中的量子混沌和信息置乱。随机酉矩阵构成了幺正群上的哈尔测度，其生成的动力学类似于具有极高局部相互作用的多体哈密顿量演化。在量子热力学中，随机电路被广泛用作马尔可夫随机过程的量子对应物，用于模拟量子系统中的热化过程。此外，Sachdev-Ye-Kitaev (SYK) 模型等重要的全息量子引力模型，其动力学行为也与随机电路的高度纠缠特性直接相关。

2. **在量子纠错（QEC）与量子基准测试中的应用**：随机电路的高随机性使其成为评估量子硬件噪声和相干性的绝佳工具。著名的“交叉熵基准测试”正是基于RCS提出的，它不仅能验证量子优越性，还能精确提取多比特系统的全局保真度。在量子纠错领域，研究人员利用含噪声的随机电路来研究量子纠错码的阈值界限，特别是分析相干噪声和非相干噪声在长时演化中的差异，从而指导容错量子体系结构的设计。

3. **在量子机器学习（QML）中的潜力**：随机电路常被用作量子神经网络（QNN）的初始架构或量子核函数。由于高度随机的电路能够产生极其丰富的特征映射，它们在量子支持向量机等机器学习任务中展现出强大的表达能力。探索受控的随机电路而非完全随机的电路，正在成为设计高效量子参数化线路的重要思路。

import std;

qbit q[4];

procedure main() {
    // 初始化层：施加Hadamard门构建全局叠加态
    for i in 0:4 {
        H(q[i]);
    }
    
    // 周期1：随机单比特旋转层
    // 实际应用中角度由伪随机数生成器产生

    Ry(4.56, q[1]);
    Rz(2.34, q[2]);
    Rx(3.14, q[3]);
    
    // 纠缠层：交替的最近邻CNOT门以传播纠缠
    CNOT(q[0], q[1]);
    CNOT(q[2], q[3]);
    CNOT(q[1], q[2]);
    
    // 周期2：继续施加随机旋转和反向结构的CNOT
    Ry(0.98, q[0]);
    Rz(5.67, q[1]);
    Rx(1.11, q[2]);
    Ry(2.22, q[3]);
    
    CNOT(q[1], q[2]);
    CNOT(q[0], q[1]);
    CNOT(q[2], q[3]);
    
    // 最终测量以获得输出分布采样
    for i in 0:4 {
        M(q[i]);
    }
}

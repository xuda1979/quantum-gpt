在超导量子计算中，随着物理比特数量的增加，量子态的操控不可避免地会受到控制线微波串扰和寄生电容/电感带来的静态耦合串扰的影响。我们可以从以下两个数学视角对其进行严谨的形式化描述：

**1. 相干哈密顿量视角**
假设系统包含 $N$ 个超导量子比特，在旋转坐标系下，理想的多比特控制哈密顿量可以表示为：
$$H_{ideal}(t) = \sum_{j=1}^{N} \frac{\Omega_j(t)}{2} \left( \cos\phi_j X_j + \sin\phi_j Y_j \right)$$
其中 $\Omega_j(t)$ 是比特 $j$ 上的微波包络，$\phi_j$ 为相位，$X_j, Y_j$ 是作用在第 $j$ 个比特上的 Pauli 算符。

**微波控制串扰**表现为施加在目标比特 $k$ 上的微波信号，由于空间电磁耦合泄漏到了非目标比特 $j$ 上。该串扰哈密顿量可写为：
$$H_{CT}(t) = \sum_{j \neq k} \frac{\epsilon_{jk} \Omega_k(t)}{2} \left( \cos\phi_k X_j + \sin\phi_k Y_j \right)$$
其中 $\epsilon_{jk}$ 是微波泄漏因子。

**静态寄生耦合串扰**通常来源于相邻比特间的残留相互作用（如横向 $XX$ 耦合的二阶效应引起的 $ZZ$ 耦合）。此时的系统总哈密顿量 $H_{total}(t)$ 为：
$$H_{total}(t) = H_{ideal}(t) + H_{CT}(t) + \sum_{j<l} \frac{\zeta_{jl}}{2} Z_j \otimes Z_l$$
系统量子态 $|\psi(t)\rangle$ 的相干演化由含时薛定谔方程严格决定：

在严谨的凝聚态物理与拓扑量子场论框架下，马约拉纳零能模（Majorana Zero Modes, MZMs）被严格定义为一维拓扑超导体（如Kitaev链模型）或二维手性p波超导体中，受系统固有对称性（如粒子-空穴对称性，Particle-Hole Symmetry）保护的、位于超导能隙中央且能量严格为零的拓扑边缘态。其核心数学本质是Bogoliubov-de Gennes (BdG) 哈密顿量中满足特殊对称性的本征激发。MZM的场算符具有自共轭特性，即产生算符等于湮灭算符，这意味着它的反粒子即为其自身。

为了从数学上严格构造并理解其非阿贝尔统计特性，我们通过一维无自旋p波超导体的Kitaev链哈密顿量进行代数推导：
⋰
考虑包含N个格点的一维Kitaev链，其二次量子化哈密顿量表示为：
H = -μ ∑ c†_j c_j - t ∑ (c†_j c_{j+1} + h.c.) + Δ ∑ (c_j c_{j+1} + h.c.)
其中 μ 为化学势，t 为跃迁幅度，Δ 为p波超导配对势。
引入马约拉纳算符分解电子湮灭算符 c_j：
c_j = (1/2)(γ_{2j-1} + i γ_{2j})
c†_j = (1/2)(γ_{2j-1} - i γ_{2j})
由此定义满足克利福德代数的马约拉纳算符：
γ_k = γ†_k,  {γ_k, γ_l} = 2δ_{kl} I

在深拓扑相极限下（t=Δ≠0 且 μ=0），哈密顿量退耦为：
H = i t ∑ γ_{2j} γ_{2j+1}
观察上式可知，γ_1 和 γ_{2N} 完全没有出现在哈密顿量中。这意味着链的两端各存在一个零能的本征模，即马约拉纳零能模。它们满足 [H, γ_{1,2N}] = 0，且在空间上相互指数级分离。

拓扑量子计算的核心在于非阿贝尔任意子的“编织”。假设存在2n个MZMs，它们可两两组合成n个常规费米子态，系统的基态流形具有 2^{n-1} 重拓扑简并。将马约拉纳算符 γ_i 和 γ_j 在实空间进行连续的绝热交换（编织操作记为 σ_i），等效的线性幺正演化算符 U_{ij}（即辫群 Braid group B_{2n} 的矩阵表示）为：
U_{ij} = exp(± (π/4) γ_i γ_j) = (1/√2)(1 ± γ_i γ_j)

⋰

总结而言，MZM是受超导能隙与拓扑不变量（如一维系统的 Z_2 拓扑不变量）双重保护的零能边缘态。其非阿贝尔编织操作构成了辫群的非阿贝尔表示，可直接映射为容错的量子逻辑门，从而为构建无需主动纠错的固态拓扑量子计算机提供了最坚实的物理与数学基础。

在量子硬件中，任何物理量子门都可以被形式化为一个量子通道（完全正保迹映射，CPTP），我们可以使用Dirac符号和算符和表示来严格表述其保真度。设系统的Hilbert空间维度为 $d$（对于 $n$ 个量子比特，$d=2^n$）。理想量子门是一个酉操作 $U$，而实际物理硬件执行的是一个量子通道 $\mathcal{E}$。为了评估 $\mathcal{E}$ 相对于 $U$ 的质量，我们通常考察通道 $\tilde{\mathcal{E}}$，定义为 $\tilde{\mathcal{E}}(\rho) = U^\dagger \mathcal{E}(\rho) U$。这样，我们将问题转化为评估实际通道 $\tilde{\mathcal{E}}$ 与理想恒等通道 $\mathcal{I}$ 之间的差异。平均门保真度（Average Gate Fidelity, $F_{avg}$）定义为在所有可能的纯态输入 $|\psi\rangle$ 上，输出态 $\tilde{\mathcal{E}}(|\psi\rangle\langle\psi|)$ 与理想输出态 $|\psi\rangle\langle\psi|$ 之间保真度的均匀平均。其数学表达式为：$$ F_{avg}(\mathcal{E}, U) = \int d\psi \langle\psi| \tilde{\mathcal{E}}(|\psi\rangle\langle\psi|) |\psi\rangle $$其中，积分是在整个Hilbert空间上使用唯一且均匀的Haar测度进行的。为了将这个积分转化为更易处理的代数形式，我们将通道 $\tilde{\mathcal{E}}$ 用其Kraus算符 $\tilde{E}_k$ 展开，即 $\tilde{\mathcal{E}}(\rho) = \sum_k \tilde{E}_k \rho \tilde{E}_k^\dagger$。通过利用Haar测度积分的对称性性质 $\int d\psi \, A |\psi\rangle\langle\psi| B |\psi\rangle\langle\psi| = \frac{\text{Tr}(A)\text{Tr}(B) + \text{Tr}(AB)}{d(d+1)}$，我们可以推导出：$$ F_{avg}(\mathcal{E}, U) = \frac{\sum_k |\text{Tr}(\tilde{E}_k)|^2 + d}{d(d+1)} $$另一方面，量子通道也可以用过程矩阵（或 $\chi$ 矩阵）在Pauli基 $\{P_m\}$ 下表示：$\tilde{\mathcal{E}}(\rho) = \sum_{m,n} \chi_{m,n} P_m \rho P_n^\dagger$。由于Pauli基是正交的，且 $P_0 = I$（恒等算符），我们可以定义过程保真度（Process Fidelity, $F_{pro}$）为过程矩阵中对应于恒等操作的矩阵元，即理想操作的“权重”：$$ F_{pro} = \chi_{0,0} = \frac{1}{d^2} \sum_k |\text{Tr}(\tilde{E}_k)|^2 $$对比上述两个公式，我们可以严格推导出平均门保真度与过程保真度之间的精确数学关系：$$ F_{avg} = \frac{d F_{pro} + 1}{d + 1} $$这个数学关系在量子硬件测试中至关重要。由于平均门保真度对初态进行了全局平均，而过程保真度衡量的是通道本身在超算符空间的范数投影，该公式揭示了随机基准测试（RB）测得的衰减率（与 $F_{avg}$ 相关）与量子过程层析成像提取的通道质量（$F_{pro}$）之间的深刻代数联系。

### Reference answer

在量子计算硬件中，退相干是破坏量子信息的主要因素。理解并测量退相干时间对于评估量子比特的质量至关重要。这里我们重点讨论两个核心时间参数：

1. **T1（纵向弛豫时间）**：描述量子比特从激发态|1⟩弛豫回基态|0⟩的过程，对应于布洛赫球上矢量长度的纵向缩短，这是由量子系统与环境的能量交换引起的。
2. **T2（横向弛豫时间/失相时间）**：描述量子比特失去叠加态相位关系的过程。在布洛赫球上表现为矢量在赤道平面上的随机分散（横向缩短）。T2不仅受T1能量弛豫的限制，还受到纯粹相位噪声的影响，通常有 $T_2 \le 2T_1$。

为了测量T2并区分不可逆的随机退相干和可逆的确定性相位演化，量子硬件中常使用**自旋回波（Spin Echo）**序列。其核心逻辑是：在一段自由演化时间的中间插入一个X门（π脉冲），它可以反转由于恒定频率偏移（如磁场不均匀）引起的确定性相位积累，从而使得在总演化时间结束后，确定性相位被完全抵消，剩下的衰减就真实反映了不可逆的T2退相干。

以下是使用isQ语言编写的自旋回波实验电路程序。为了模拟真实环境中的相位演化，我们在电路中加入了等效的相位旋转门：

```isQ
import std;

// 声明用于实验的量子比特和经典寄存器
qbit q[1];
creg c[1];

procedure main() {
    // 步骤 1：初始化量子态为叠加态 |+>
    // 将量子态从Z轴的|0>旋转到X轴，开始追踪横向弛豫
    H(q[0]);
    
    // 步骤 2：第一段自由演化阶段 (时间 tau)
    // 在实际硬件中，这段时间量子比特会发生退相干。
    // 这里用 Rz 门模拟由于环境噪声导致的确定性相位漂移。
    Rz(0.8, q[0]); 
    
    // 步骤 3：施加回波脉冲
    // 执行 X 门操作，相当于在布洛赫球上绕X轴旋转180度。
    // 它将量子态的相位“镜像”翻转，为抵消确定性相位误差做准备。
    X(q[0]);
    
    // 步骤 4：第二段自由演化阶段 (时间 tau)
    // 继续经历相同的环境噪声。由于X门的作用，之前的确定性相位漂移
    // (如+0.8) 会被现在的反向漂移 (如-0.8) 完全抵消。
    Rz(-0.8, q[0]); 
    
    // 步骤 5：干涉与测量
    // 再次施加 H 门，将横向的相位信息重新映射回纵向（|0>和|1>的概率）上。
    H(q[0]);
    
    // 如果只有确定性失相，理论上测量结果应100%为|0>。
    // 如果在实际硬件中运行，由于不可逆的T2退相干和T1弛豫，
    // 测得|0>的概率将按照 exp(-2*tau/T2) 的指数规律衰减。
    c[0] = M(q[0]);
}
```

通过编写上述isQ程序并在不同延迟时间下运行（通过改变Rz的模拟角度或实际硬件中的延迟时间），我们可以观察到量子态保真度的变化。这种自旋回波序列是当前超导量子计算、离子阱等物理体系中标定T2退相干时间的标准方法，它深刻体现了量子操控对抵抗环境噪声、提取真实硬件参数的重要作用。

量子随机数生成器（QRNG）的核心在于利用量子态的叠加性和测量的本质随机性来生成不可预测的随机数。从数学形式化的角度来看，我们可以通过希尔伯特空间中的状态向量和幺正演化来精确描述这一过程。

首先，考虑一个最简单的QRNG模型，它基于单个量子比特（Qubit）的测量。在二维复希尔伯特空间$\mathcal{H} \cong \mathbb{C}^2$中，计算基矢（标准基）通常被选定为$|0\rangle$和$|1\rangle$。在QRNG的初始化阶段，量子比特通常被制备为确定的基态，其状态向量可以表示为：
$$ |\psi_0\rangle = |0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix} $$

为了生成随机比特（0或1），我们需要让系统进入基态的叠加态。这通过对初始态施加阿达马门（Hadamard gate，记为$H$）来实现。阿达马算符的矩阵表示为：
$$ H = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} $$

对初始态$|0\rangle$应用该算符，演化过程可以表示为算符作用于状态向量：
$$ |\psi_1\rangle = H |\psi_0\rangle = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) $$

此时，系统处于等概率的叠加态$|\psi_1\rangle$。QRNG的真随机性源自于量子测量公设。当我们在计算基$\{|0\rangle, |1\rangle\}$下对该量子比特进行投影测量时，系统的状态会发生坍缩。

测量的过程在数学上由一组投影算符完全描述。对应于输出0和1的投影算符分别为：
$$ P_0 = |0\rangle \langle 0| = \begin{pmatrix} 1 \\ 0 \end{pmatrix} \begin{pmatrix} 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} $$
$$ P_1 = |1\rangle \langle 1| = \begin{pmatrix} 0 \\ 1 \end{pmatrix} \begin{pmatrix} 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} $$

根据玻恩法则（Born Rule），测量结果为$r \in \{0, 1\}$的概率由测量前状态与投影算符的期望值给出：
$$ p(r) = \langle \psi_1 | P_r | \psi_1 \rangle $$

我们可以具体计算出得到0和1的概率：
$$ p(0) = \left( \frac{1}{\sqrt{2}}(\langle 0| + \langle 1|) \right) |0\rangle \langle 0| \left( \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) \right) = \frac{1}{2} |\langle 0|0\rangle + \langle 1|0\rangle|^2 = \frac{1}{2} |1 + 0|^2 = \frac{1}{2} $$
$$ p(1) = \left( \frac{1}{\sqrt{2}}(\langle 0| + \langle 1|) \right) |1\rangle \langle 1| \left( \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) \right) = \frac{1}{2} |\langle 0|1\rangle + \langle 1|1\rangle|^2 = \frac{1}{2} |0 + 1|^2 = \frac{1}{2} $$

这从数学上严格证明了通过该量子电路生成的随机变量具有均匀分布$B(1, 1/2)$。由于量子态坍缩本身在量子力学中被认为是根本无规律且不可预测的（不同于经典伪随机数生成器依赖于确定性混沌算法），因此所生成的序列具备极高的信息熵。

```isq

    // 初始状态默认为 |0⟩
    // 施加H门进入叠加态
    H(q[0]);
    
    // 在计算基下测量，结果存储在经典变量r中
    // r将以50%的概率等于0或1，实现QRNG

}
```

### 量子增强机器学习的原理

量子增强的核心在于利用量子态的希尔伯特空间作为高维特征空间。经典数据需要通过“数据编码”过程映射到量子态上。假设有一个经典数据向量 $\vec{x}$，我们可以通过参数化量子电路将其编码为量子态 $|\psi(\vec{x})\rangle$。

通过量子电路测量获得这个核矩阵后，再交由经典的SVM求解器进行分类。

### Reference answer

供应链优化是现代工业和商业面临的最复杂的挑战之一，其核心通常是组合优化问题（属于NP-Hard问题）。随着问题规模的增大，经典计算机往往只能给出近似解。量子计算凭借其量子叠加和量子干涉的特性，能够在庞大的解空间中更高效地寻找全局最优解或高质量近似解。

量子计算在供应链优化中的主要应用包括以下几个方面：

1. **车辆路径规划（VRP）与物流调度**
VRP旨在为车队找到访问一组节点的最优路径集合，以最小化总行驶距离或成本。我们可以将其映射为二次无约束二值优化（QUBO）模型。数学上，我们需要最小化哈密顿量：
$$ H = \sum_{i,j,t} C_{ij} x_{i,t} x_{j,t+1} + P \left( \sum_t x_{i,t} - 1 \right)^2 $$
其中，$x_{i,t} \in \{0, 1\}$ 表示在时间步 $t$ 是否访问了节点 $i$，$C_{ij}$ 是距离或成本权重，$P$ 是确保每个节点只被访问一次的惩罚系数。通过量子退火或量子近似优化算法（QAOA），可以高效求解该QUBO模型。

2. **库存管理**
在多级供应链中，平衡库存成本与缺货风险是一个动态优化问题。量子优化算法可以快速分析不同需求场景，寻找最优的安全库存水平和补货策略。

3. **网络设计与设施选址**
决定仓库或工厂的最优建设位置以最大化服务效率并最小化建设及运输成本。此类问题同样可以通过构建QUBO或Ising模型交由量子计算机处理。

- **大众汽车与D-Wave**：大众汽车曾利用D-Wave的量子退火机对北京的交通流量进行优化，这本质上是一个旅行商问题（TSP）和VRP的应用。通过将公交车队和私家车的路线进行全局优化，有效减少了交通拥堵。
- **埃森哲与Biogen**：埃森哲开发了一种基于量子计算的分子比较方法，用于优化生物制药的供应链和药物研发周期。

**算法实现示例（QAOA电路的isQ代码框架）：**
在门级量子计算机上，我们通常使用QAOA来处理这些供应链的QUBO模型。以下是一段用于执行单步QAOA（p=1）的isQ代码示例，展示了如何通过参数化量子电路寻找供应链成本哈密顿量的基态：

```isq

qbit q[3];

// 定义ZZ相互作用门，用于编码供应链问题的成本（如两地之间的运输成本）
procedure ZZ_interaction(double gamma, int c, int t) {
    CNOT(q[c], q[t]);
    Rz(2.0 * gamma, q[t]);
    CNOT(q[c], q[t]);
}

procedure main() {
    // 1. 制备均匀叠加态（代表所有可能的路线组合）
    H(q[0]);
    H(q[1]);
    H(q[2]);

    // 2. 应用成本哈密顿量 U_C(gamma)
    // 假设供应链成本矩阵中，节点0-1和1-2之间存在高成本连接
    double gamma = 0.5;
    ZZ_interaction(gamma, 0, 1);
    ZZ_interaction(gamma, 1, 2);

    // 3. 应用混合哈密顿量 U_B(beta)
    double beta = 0.3;
    Rx(2.0 * beta, q[0]);
    Rx(2.0 * beta, q[1]);
    Rx(2.0 * beta, q[2]);

    // 4. 测量输出，经过多次采样后统计出现频率最高的比特串，即为较优的物流分配方案
    M(q[0]);
    M(q[1]);
    M(q[2]);
}
```

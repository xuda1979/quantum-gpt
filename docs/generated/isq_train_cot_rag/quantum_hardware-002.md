Google Willow处理器的核心突破在于首次在实验中证明了随着表面码距离的增加，量子纠错能够以指数级压低逻辑错误率，这标志着我们跨越了量子纠错的盈亏平衡点。要形式化地描述这一过程，我们需要从稳定子形式化体系切入。

在表面码中，我们将单个逻辑量子比特编码到由 $n = 2d^2 - 2d + 1$ 个物理量子比特构成的二维网格中，其中 $d$ 为奇数，代表码距。该纠错码的数学基础建立在阿贝尔稳定子群 $\mathcal{S}$ 上。对于一个码距为 $d$ 的表面码，稳定子群由 $n-1$ 个相互对易的局域泡利算子张量积生成，这些生成元分为 $X$ 型和 $Z$ 型。

稳定子码的合法码空间 $\mathcal{C}$ 是所有生成元的共同 $+1$ 本征空间，其数学定义为：
$$ \mathcal{C} = \{ |\psi\rangle \in \mathcal{H}_2^{\otimes n} \mid S_i |\psi\rangle = |\psi\rangle, \forall S_i \in \mathcal{S} \} $$
为了在不破坏量子态的前提下提取错误信息，我们必须对稳定子生成元进行多体投影测量。对于 $Z$ 型稳定子 $S_Z = Z_1 \otimes Z_2 \otimes Z_3 \otimes Z_4$，我们引入一个辅助量子比特 $a$，通过酉算子 $U_{CZ}$（受控-$Z$ 门系列）将数据量子比特与辅助量子比特纠缠。设初始数据态与辅助态处于 $|\psi\rangle \otimes |0\rangle$，测量过程可表示为：
$$ (|0\rangle\langle 0|_a \otimes I) U_{CNOT} (|\psi\rangle \otimes |0\rangle) = \frac{1}{2}[(I + S_Z)|\psi\rangle] \otimes |0\rangle $$
$$ (|1\rangle\langle 1|_a \otimes I) U_{CNOT} (|\psi\rangle \otimes |0\rangle) = \frac{1}{2}[(I - S_Z)|\psi\rangle] \otimes |1\rangle $$
测量结果的期望值 $\langle S_Z \rangle$ 为 $\pm 1$，一旦出现 $-1$（即测得辅助比特为1），意味着系统发生了与 $S_Z$ 不对易的错误（如翻转错误），从而生成错误伴随式。

$$ \epsilon_L(d) = A \left(\frac{p}{p_{th}}\right)^{\frac{d+1}{2}} $$
其中 $A$ 是与具体硬件架构相关的常数。在 Willow 实验中，随着码距从 $d=3$ 增加到 $d=5$ 再增加到 $d=7$，逻辑错误率 $\epsilon_L$ 呈现出明显的指数级减半现象。

### Reference answer

要理解T1和T2，我们首先要明白量子比特非常“娇贵”，它们很容易受到外界环境（比如热量、电磁波等）的干扰而失去量子态。T1和T2就是用来衡量量子比特能“坚持”多久的两个不同的寿命指标。

我们可以用“旋转的陀螺”或者“手机电池”来打比方。

首先来说T1时间，它学名叫“能量弛豫时间”。你可以把它想象成一部漏电的手机电池，或者一个在桌面上旋转的陀螺。当你给手机充满电（或者用力让陀螺高速旋转）时，这相当于量子比特处于“1”的状态。但是，电池会自然地漏电，陀螺也会因为桌面的摩擦力慢慢停下来，最终变成没电的状态，或者静止不动的“0”状态。在这个从“1”回到“0”的过程中，量子比特的能量丢失了。T1时间就是衡量这个“电量耗尽”过程有多慢的指标。如果在T1时间之内你没有完成计算，你的量子比特就没电了，计算结果自然也就毁了。

接着我们来说T2时间，它的学名叫“相位退相干时间”。这个概念稍微抽象一点，它关乎的是量子态的“一致性”或“节奏”。这次我们用“合唱团”来打比方。量子比特的强大之处在于它可以处于“0”和“1”的叠加态，就像合唱团里有人唱高音，有人唱低音。更关键的是，他们必须节奏完全一致、声音高度和谐（这在物理学上叫“相位相干”），这样才能交织出美妙的和声（对应于量子计算中的干涉和算法效果）。

现在，外界环境（比如微小的微风或者观众的咳嗽声）开始干扰合唱团。这些干扰并不会让歌手立刻闭嘴（也就是没有发生T1那样的能量丢失），但是会让歌手们分心，导致有人唱得快了半拍，有人唱得慢了半拍。很快，原本和谐美妙的和声消失了，变成了一群人各自为政、毫无规律的嘈杂声。这种“失去节奏同步性”的过程，就是退相干。T2时间就是衡量这个“合唱团从和谐走向嘈杂”能坚持多久的时间。

为什么T2通常比T1更短、更脆弱呢？因为破坏节奏（T2）比让人彻底闭嘴（T1）要容易得多。任何极其微小的外界风吹草动，哪怕完全没有消耗歌手的体力（没有发生能量弛豫），也会瞬间打乱合唱团的节拍。不仅如此，如果歌手因为体力耗尽而倒下了（T1发生），那合唱团的节奏（T2）自然也就彻底没有了。因此，维持量子比特的“节奏”（T2）是量子计算中最困难的一环，这也是为什么科学家们拼命要把量子计算机冷却到接近绝对零度、并做好极好的屏蔽——目的就是为了让这个“合唱团”能多和谐哪怕一微秒的时间。

### Reference answer

中性原子量子计算是一种利用光镊阵列或光晶格捕获并操控中性原子（如铷、铯、锶等碱金属或碱土金属原子）来实现量子计算的物理方案。与超导离子阱等平台不同，中性原子系统具有高度的可扩展性、长相干时间以及能够在室温超高真空环境下运行的优势。在该系统中，量子比特通常被编码在原子的两个超精细基态能级（例如记作 $|0
angle$ 和 $|1
angle$）上。

为了实现量子比特之间的双比特逻辑门操作，中性原子量子计算引入了**里德伯态**。里德伯态是指原子的外层电子被激发到主量子数 $n$ 很高（通常在50到100之间）的能级状态。处于里德伯态的原子具有极大的电子轨道半径，因此其极化率非常高，导致里德伯原子之间会产生极强的长程相互作用（如范德华力 $\propto 1/R^6$ 或偶极-偶极相互作用 $\propto 1/R^3$）。

利用这种强烈的相互作用，可以产生所谓的**里德堡阻塞效应**：当两个原子距离足够近时，如果其中一个原子已经被激发到里德伯态 $|r\rangle$，那么由于强烈的排斥作用，系统能量的改变会使得第二个原子无法再被共振激发到同一个里德伯态。

基于里德堡阻塞效应，我们可以实现受控量子门（如 CZ 门或 CNOT 门）。以实现 CZ 门为例，其物理过程如下：

1. 控制比特 $q_c$ 和目标比特 $q_t$ 初始处于基态 $|0\rangle$ 或 $|1\rangle$。我们使用 $|1\rangle$ 作为计算基态，并设定一个高能级里德伯态 $|r\rangle$。
2. 对控制比特 $q_c$ 施加一个 $\pi$ 脉冲（$R_y(\pi)$）：如果 $q_c$ 处于 $|1\rangle$ 态，则将其激发到 $|r\rangle$ 态；如果处于 $|0\rangle$ 态则不发生改变。
3. 对目标比特 $q_t$ 施加一个 $2\pi$ 脉冲（即 $R_y(2\pi)$），此脉冲本应让状态在 $|1\rangle$ 和 $|r\rangle$ 之间经历一个完整的拉比振荡并回到原状态，同时产生一个 $\pi$ 的相位积累。
4. **阻塞效应发生**：如果 $q_c$ 在第2步被激发到了 $|r\rangle$，那么第3步中 $q_t$ 向 $|r\rangle$ 的跃迁将被阻塞，不会经历拉比振荡，因此不产生相位积累。如果 $q_c$ 未被激发，$q_t$ 正常完成振荡并积累 $\pi$ 相位。
5. 最后对 $q_c$ 再次施加反向的 $\pi$ 脉冲，将其从 $|r\rangle$ 退激发回 $|1\rangle$。

通过上述脉冲序列，只有当 $q_c$ 和 $q_t$ 都处于 $|1\rangle$ 态时（即 $|11\rangle$），系统才不会经历完整的拉比振荡，从而相比其他状态产生了相对相位差。这等效于在目标比特上施加了一个 $Z$ 操作，构成了受控相位门。

在逻辑电路设计层面，我们依然可以使用标准的门集来描述。以下是在 isQ 代码中描述如何使用上述底层原理构建的受控门来实现一个贝尔态（Bell State）的示例：

```isq
import std;

qbit q[2];

procedure main() {
    // 初始化为 |00>
    // 对第一个量子比特（控制比特）施加Hadamard门
    H(q[0]);
    
    // 利用中性原子里德堡阻塞等效的CNOT门
    // 在硬件底层，该CNOT会被编译为上述的里德堡脉冲序列
    CNOT(q[0], q[1]);
    
    // 此时的量子态处于贝尔态 (|00> + |11>) / sqrt(2)
    
    // 测量
    M(q[0]);
    M(q[1]);
}
```

总而言之，中性原子量子计算通过将中性原子束缚在光镊中，并巧妙地利用里德伯态的巨大偶极相互作用引发的阻塞效应，成功实现了高保真度的双量子比特门。这种技术在实现大规模量子寄存器和量子模拟方面具有极其广阔的前景。

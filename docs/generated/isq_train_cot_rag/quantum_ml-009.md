### Reference answer

### Reference answer

量子卷积神经网络（Quantum Convolutional Neural Network, 简称QCNN）是一种专门为量子计算架构设计的参数化量子机器学习模型。它通过将经典卷积神经网络中的局部感受野、权值共享和空间下采样等核心概念映射到希尔伯特空间中，从而实现对量子多体态的高效分类或特征提取。从严格的数学和物理学角度来看，QCNN可以被定义为一个基于多尺度纠缠重整化假设的参数化量子电路簇。

在数学形式上，给定一个作用在 $N$ 个量子比特上的输入量子态 $\rho_{in} \in \mathcal{H}^{\otimes N}$，QCNN的演化过程可以通过一个由参数 $\vec{\theta}$ 驱动的深度酉算符 $U(\vec{\theta})$ 来描述，其输出可以表示为期望值的映射 $f(\rho_{in}, \vec{\theta}) = \text{Tr}[U(\vec{\theta}) \rho_{in} U^\dagger(\vec{\theta}) O]$，其中 $O$ 为最终待测量的可观测量。QCNN的核心结构由交替的卷积层和池化层构成。

首先，在卷积层中，操作被定义为具有局域性和平移不变性的参数化酉算符。具体而言，卷积操作由一系列作用在相邻量子比特上的两比特门构成，可表示为 $U_{conv}^{(l)}(\theta^{(l)}) = \prod_{i \in \text{Even}} U^{(l)}(\theta^{(l)})_{i, i+1} \prod_{j \in \text{Odd}} U^{(l)}(\theta^{(l)})_{j, j+1}$，其中 $U^{(l)}$ 通常由通用双比特门的分解构成。这种层级的局部纠缠操作与张量网络理论中的TNR（Tensor Network Renormalization）或MERA中的Isometry和Disentangler等价。

其次，池化层在数学和物理上对应于自由度的粗粒化与希尔伯特空间维度的约化。不同于经典CNN直接丢弃像素，QCNN的池化层通常通过测量部分量子比特，并根据测量结果对剩余量子比特施加条件酉操作来实现纠缠的局域化。从多体物理的角度来看，这对应于实空间重整化群（RG）变换。系统依次经过卷积（提取短程纠缠）和池化（整合自由度）后，有效的量子比特数呈指数级递减（如 $N \to N/2 \to N/4 \dots$）。因此，QCNN不仅是一个分类器，其底层架构本质上是张量网络态MERA的逆向展开，这使得它在表示具有多尺度纠缠特征的量子态（如拓扑序、对称性破缺态）时，具有相较于经典模型更强的表达能力，且其参数量随系统规模仅呈对数增长，有效克服了常规参数化量子电路遭遇的贫瘠高原现象。

### Reference answer

量子机器学习（Quantum Machine Learning, QML）是一个将量子计算与机器学习相结合的交叉领域。根据数据的计算性质与处理设备的性质，QML通常被分为四大类：CC（经典数据-经典处理）、CQ（经典数据-量子处理）、QC（量子数据-经典处理）和QQ（量子数据-量子处理）。目前最具应用前景且被NISQ（含噪声中等规模量子）设备广泛支持的类别是CQ类，即利用量子计算机处理经典数据。

在CQ类中，**参数化量子电路（Parameterized Quantum Circuits, PQC）**构成了绝大多数算法（如变分量子本征求解器VQE、量子神经网络QNN等）的核心。在数学上，PQC可以表示为一个带有可调参数向量 $\vec{\theta}$ 的酉算子 $U(\vec{\theta})$。其数学模型通常表现为固定纠缠门与参数化旋转门的交替作用：$U(\vec{\theta}) = \prod_{k} V_k U_k(\vec{\theta_k})$。其中，$V_k$ 是固定的多量子比特纠缠门（如CNOT），用于引入量子态之间的非线性关联与纠缠；$U_k(\vec{\theta_k})$ 则由一系列参数化的单比特旋转门（如 $R_x, R_y, R_z$）构成，对应于经典神经网络中的权重矩阵，在训练过程中不断更新以最小化损失函数。

下面是一个使用isQ语言编写的量子机器学习程序示例。该程序实现了一个针对2个量子比特的简单量子神经网络结构，完整展示了“数据编码 -> 参数化旋转 -> 量子纠缠 -> 测量输出”的混合计算流程：

```isq
import std;

// 全局声明2个量子比特
qbit q[2];

procedure main() {
    // 定义经典可训练参数（在实际QML框架中由经典优化器如Adam更新）
    real theta0 = 0.523; 
    real theta1 = 1.047;
    real theta2 = 0.785;
    real theta3 = 1.57;

    // 1. 数据编码层 (特征映射)
    // 将经典数据映射到量子态，此处使用H门构造均匀叠加态
    H(q[0]);
    H(q[1]);

    // 2. 第一层参数化旋转 (可学习权重层)
    // 对应数学上的酉矩阵 $e^{-i \theta Y / 2}$
    Ry(theta0, q[0]);
    Ry(theta1, q[1]);

    // 3. 纠缠层 (引入非线性与高维关联)
    // 使用CNOT门在两比特间建立量子关联
    CNOT(q[0], q[1]);

    // 4. 第二层参数化旋转 (加深网络表达能力)
    Ry(theta2, q[0]);
    Ry(theta3, q[1]);

    // 5. 测量层
    // 将量子态映射回经典概率分布
    int r0 = M(q[0]);
    int r1 = M(q[1]);

    // 经典条件控制：根据测量得到的经典结果执行相应操作
    if (r0 == 1) {
        X(q[1]);
    }
}
```

**代码与概念解析：**
1. **特征映射**：程序开头的 `H` 门将初始基态 $|00\rangle$ 变换为叠加态。在量子机器学习中，这一步等价于将经典输入数据编码到高维希尔伯特空间中。
2. **参数化酉演化**：`Ry(theta, q[i])` 门实现了围绕Y轴的旋转。这里的变量 `theta` 充当机器学习模型中待训练的“权重”。通过改变这些角度，量子电路能够拟合复杂的函数。
3. **量子纠缠**：`CNOT(q[0], q[1])` 是不可分离的量子操作，它使得两个量子比特的状态相互依赖。这种纠缠机制是量子机器学习超越经典线性模型、展现“量子优势”的关键来源。
4. **闭环训练**：末尾的 `M(q[i])` 测量操作将量子信息转化为经典的0或1。在完整的QML训练循环中，系统会多次运行此电路以统计输出分布，并计算与真实标签之间的损失，随后由经典计算机计算梯度并更新 `theta` 变量，再重新传入量子电路，从而完成“量子推演-经典优化”的混合训练过程。

### Reference answer

数据重上传（Data Re-uploading）是量子机器学习中一种极为巧妙的变分量子电路设计范式。在传统的量子分类器或神经网络中，经典数据通常只在量子电路的最开始被编码一次（例如通过振幅编码或角度编码），随后量子门只负责进行参数化的酉变换。然而，这种单次编码方式严重限制了模型的表达能力，特别是当可用量子比特数量较少时，单比特量子模型的计算能力严格受限，只能解决线性可分的问题。

数据重上传技术的核心思想是：打破量子计算中“不可克隆定理”对数据复用的限制，通过在量子电路的多个中间层**重复地**将相同的经典数据编码到同一个量子比特上。在数学机制上，这相当于在布洛赫球面上，对量子态交替施加“依赖于数据的旋转”和“依赖于参数的旋转”。每一次数据重上传都可以看作是一层非线性特征映射，它使得即使是一个没有任何纠缠的单量子比特电路，也能够构建出深度非线性模型，并在理论上被证明可以作为通用函数近似器，其能力等价于经典的深层神经网络。

为了直观展示这一概念，下面我使用isQ语言编写了一个单量子比特的量子神经网络电路。该电路包含三个数据重上传层。在每一层中，经典特征 `[x0, x1]` 被作为旋转角度重新编码到量子比特上，随后紧跟着一个由可训练参数 `[theta...]` 控制的酉变换。最终通过测量来输出分类结果。

```isQ
import std;

qbit q[1];

procedure main() {
    // 假设我们有一个二维的经典数据样本特征 x0 和 x1
    // 在实际的量子机器学习训练中，这些值将由经典数据集提供
    double x0 = 0.5;
    double x1 = -0.3;

    // ============ 第 1 层：初始数据编码与变换 ============
    // 将经典数据映射为布洛赫球上的旋转
    Rx(x0, q[0]);
    Rz(x1, q[0]);
    // 应用可训练的参数旋转（偏置与权重）
    Ry(0.1, q[0]);
    Rz(0.2, q[0]);

    // ============ 第 2 层：第一次数据重上传 ============
    // 再次将相同的经典特征 x0, x1 编码到量子态中，引入非线性表达能力
    Rx(x0, q[0]);
    Rz(x1, q[0]);
    // 应用新的一组可训练参数
    Ry(-0.4, q[0]);
    Rz(0.5, q[0]);

    // ============ 第 3 层：第二次数据重上传 ============
    // 第三次上传数据，进一步丰富特征空间的高维映射
    Rx(x0, q[0]);
    Rz(x1, q[0]);
    // 最后一层的参数化变换
    Ry(0.6, q[0]);
    Rz(-0.7, q[0]);

    // 测量：通过多次射击统计获得期望值，以此作为分类器的最终输出
    int res = M(q[0]);
}
```

$$ |\gamma, \beta\rangle = e^{-i \beta_p H_M} e^{-i \gamma_p H_C} \cdots e^{-i \beta_1 H_M} e^{-i \gamma_1 H_C} |+\rangle^\otimes n $$
这完全与DRU的分层结构同构！在QAOA中，$\gamma$ 是演化时间（类似DRU中的数据 $x$），$\beta$ 是变分参数（类似DRU中的 $\theta$）。区别在于，QAOA是为了寻找基态，而DRU是为了拟合数据流形。这种同构性意味着我们可以将QAOA看作是在图数据上的一种特殊数据重上传。

基编码（Basis Encoding）是量子机器学习中最直观的量子数据编码方法之一。它的核心思想是将一个由 N 个比特组成的经典二进制字符串直接映射为 N 个量子比特系统的计算基态。这种映射是一对一的，能够完美保留经典数据的离散结构。

从数学形式化的维度来看，设我们有一个长度为 N 的经典二进制向量 x = (x_1, x_2, ..., x_N)，其中 x_i ∈ {0, 1}。系统对应的希尔伯特空间为 H = (C^2)^{⊗N}，其维度为 2^N。

在Dirac符号下，经典数据 x 的基编码可以被定义为多体系统态矢的张量积：
| x ⟩ = | x_1, x_2, ..., x_N ⟩ = | x_1 ⟩ ⊗ | x_2 ⟩ ⊗ ··· ⊗ | x_N ⟩

其中，单量子比特的计算基态（本征态）满足：
| 0 ⟩ = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \quad | 1 ⟩ = \begin{pmatrix} 0 \\ 1 \end{pmatrix}

若要从全零的初始态 | 0 ⟩^{⊗N} 制备出目标基态 | x ⟩，我们需要构建一个特定的酉算子 U_x，使得：
| x ⟩ = U_x | 0 ⟩^{⊗N}

由于基编码的逻辑十分直接，对于每一个经典位 x_i，若 x_i = 1，则对第 i 个量子比特作用泡利-X门（即量子非门）；若 x_i = 0，则保持不变（作用恒等门 I）。因此，全局的酉操作可以表示为这些单比特操作的张量积：
U_x = \bigotimes_{i=1}^{N} X^{x_i}
其中 X^0 = I, X^1 = X。

基编码的一个重要数学特征是其严格的正交性。对于任意两个不同的经典二进制向量 x 和 y，它们映射后的量子态在希尔伯特空间中是彼此绝对正交的，即它们的内积为克罗内克δ函数：
⟨ y | x ⟩ = δ_{x,y} = \begin{cases} 1, & \text{if } x = y \\ 0, & \text{if } x \neq y \end{cases}

这种绝对正交性使得基编码在基于距离度量或内积的量子机器学习算法（如量子最近邻搜索、量子支持向量机）中极其有用。然而，这也意味着不同数据态之间没有任何重叠，未能直接利用量子叠加态在非正交子空间中提供的特殊干涉优势，且需要使用的量子比特数与经典比特数完全相等。

量子储层计算（QRC）是经典储层计算在量子领域的自然扩展，其核心思想是利用高维希尔伯特空间中的混合量子态作为储层，通过固定且复杂的量子动力学演化将输入时间序列映射到高维特征空间，最后仅需训练一个简单的经典线性读出层。下面给出完整的数学形式化表述：

1. 输入编码机制：
假设在时间步 $k$，系统接收到一个经典实值输入向量 $\mathbf{u}_k \in \mathbb{R}^m$。我们需要将其编码到量子态上。设系统的初始状态为密度矩阵 $\rho_{k-1} \in \mathcal{H}$。通常采用参数化酉变换进行编码，记输入编码酉操作为 $U_{in}(\mathbf{u}_k)$。编码过程可表示为：
$$\rho_{k}^{(in)} = U_{in}(\mathbf{u}_k) \rho_{k-1} U_{in}^\dagger(\mathbf{u}_k)$$
例如，若采用单量子比特旋转编码，$U_{in}(\mathbf{u}_k) = \exp\left(-i \sum_{j=1}^m u_{k,j} H_j \right)$，其中 $H_j$ 为特定的哈密顿量。此时量子态吸收了外部时序信息。

2. 储层动力学演化：
编码后的量子态进入量子储层进行非线性演化。量子储层由一个固定的、高度纠缠的酉算符 $U_{res}$ 主导。该演化过程不需要训练，其数学表达为：
$$\rho_{k} = U_{res} \rho_{k}^{(in)} U_{res}^\dagger = U_{res} U_{in}(\mathbf{u}_k) \rho_{k-1} U_{in}^\dagger(\mathbf{u}_k) U_{res}^\dagger$$
如果考虑开放量子系统的退相干效应，演化可能由完全正定映射（CPTP）描述：$\rho_k = \mathcal{E}_{res} \circ \mathcal{E}_{in}(\rho_{k-1})$。$N$ 个量子比特的希尔伯特空间维度为 $2^N$，这种指数级的维度扩张为系统提供了极高的短期记忆容量（Fading Memory）和丰富的动力学特性。

3. 量子测量与经典读出：
演化结束后，我们需要通过测量提取特征向量。定义一组可观测量的集合 $\mathcal{M} = \{O_1, O_2, ..., O_P\}$（如各个量子比特上的泡利算子 $\sigma_x, \sigma_y, \sigma_z$）。在时间步 $k$，通过计算这些可观测量的期望值，可以得到一个经典的 $P$ 维特征向量 $\mathbf{x}_k$，其第 $p$ 个分量为：
$$x_{k,p} = \text{Tr}(O_p \rho_k) = \langle O_p \rangle_k$$
最后，模型的预测输出 $\hat{y}_k$ 是特征向量 $\mathbf{x}_k$ 的线性组合：
$$\hat{y}_k = \mathbf{w}_{out}^T \mathbf{x}_k + b$$
其中 $\mathbf{w}_{out} \in \mathbb{R}^P$ 为读出权重，$b$ 为偏置。训练过程就是基于最小二乘法或岭回归，最小化预测值 $\hat{y}_k$ 与真实标签 $y_k$ 之间的均方误差，从而求出最优的 $\mathbf{w}_{out}$，而 $U_{in}$ 和 $U_{res}$ 始终保持不变。

import std;

qbit q[3];

procedure main() {
    // 假设经典输入 uk 被编码为旋转角度 theta
    number theta = 3.14;

    // U_in: 输入编码层，将时序数据映射到量子态
    for i in 0:3 {
        Rx(theta, q[i]);
    }

    // U_res: 固定的量子储层演化层，提供高维非线性映射
    H(q[0]);
    H(q[1]);
    H(q[2]);
    CNOT(q[0], q[1]);
    CNOT(q[1], q[2]);
    CZ(q[0], q[2]);
    Rz(1.57, q[1]);

    // 测量提取特征期望值 
    for i in 0:3 {
        M(q[i]);
    }
}

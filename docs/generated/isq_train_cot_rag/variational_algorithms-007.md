在变分量子算法（VQA）的误差缓解背景下，概率误差消除与零噪声外推（ZNE）和随机编译（RC）相比，在理论原理、适用场景及资源开销上有什么本质区别？请详细分析PEC的优缺点，并提供一段使用isQ语言实现的简单VQA框架代码，展示如何在计算期望值时引入PEC的特征操作。

### Reference answer

概率误差消除、零噪声外推和随机编译是目前NISQ时代最主流的三种量子误差缓解技术，它们在处理含噪中等规模量子计算时有着截然不同的理论动机和适用场景。零噪声外推的核心思想是通过人为放大系统噪声，获取不同噪声缩放因子下的期望值，随后利用数学外推（如线性、多项式或Richardson外推）推断出零噪声极限下的结果。ZNE的优点是实现相对简单，尤其适用于难以完全刻画底层噪声的“黑盒”系统，且资源开销主要表现为增加电路深度。然而，其高度依赖噪声随缩放因子平滑变化的假设，对于非马尔可夫噪声或存在阈值效应的系统，外推极易引入系统性偏差。随机编译则是通过将逻辑电路随机转化为一系列均匀分布的等效电路并在经典后处理中平均，将系统性的相干误差转化为随机泡利误差，从而降低硬件表征误差的影响。RC不需要完整表征噪声信道，采样开销适中，但它无法完全消除随机误差。相比之下，概率误差消除是一种基于量子信道表征和准概率分布的严格数学方法。PEC首先通过量子层析技术精确表征底层量子门的噪声信道，然后将噪声信道的逆映射分解为一组基本泡利操作的准概率线性组合。在实际执行时，通过以这些准概率分布为权重，随机采样并执行对应的泡利操作序列。由于准概率可能包含负数，因此需要引入符号函数进行采样，并在最终期望值计算中按比例恢复。PEC的最大优点在于：在噪声信道表征完全准确的前提下，它能够渐进地、无偏地消除硬件误差，甚至达到超出100%的有效保真度，这对于需要极高精度的变分量子本征求解器（VQE）求解分子基态能量至关重要。然而，PEC的代价极其高昂：其采样复杂度随电路深度和系统规模呈指数级增长（采样开销与$\chi^2$发散成正比），且严重依赖于极耗时的噪声层析过程。这使得PEC通常仅适用于浅层电路或高价值、对精度要求极其苛刻的核心子例程。总结而言，ZNE适合作为通用的、对精度要求不极端的误差缓解快速方案；RC擅长抑制硬件特性带来的相干误差；而PEC则是误差缓解的终极武器，适用于电路规模不大但需要极高精度的变分算法核心环节。为了展示在变分算法中如何考虑基本的泡利基期望值提取和逆操作（这是PEC补偿的基础），以下是isQ语言的实现示例：

### Prompt

量子机器学习和变分量子算法（如VQE、QAOA）被认为是NISQ时代实现量子优势的重要途径。然而，这些算法在实际应用中经常会遇到一个被称为“贫瘠高原”（Barren Plateau）的严重障碍。请从宏观原理出发，详细解释什么是贫瘠高原现象？并从采样复杂度、梯度方差衰减与多项式时间假设的关系，深刻分析这一现象是如何破坏变分量子算法中潜在的量子加速优势的？

### Reference answer

贫瘠高原（Barren Plateau, BPP）是变分量子算法（VQA）中特有的优化陷阱，其核心表现为：随着系统量子比特数 $N$ 的增加，参数化量子电路（PQC）损失函数的梯度方差呈指数级衰减。从宏观原理来看，当一个量子电路的深度足够深，或者其表达的酉算符过于通用时，它所生成的量子态在指数级庞大的希尔伯特空间中会表现出类似于 Haar 随机态的均匀分布。根据梯度集中现象，此时损失函数的偏导数不仅期望值为零，其方差也会迅速趋近于零，即参数空间中绝大部分区域变得极其平坦，失去了提供优化方向的梯度信息，就如同在一个广阔无垠且极其平坦的高原上寻找最低点，优化算法只能盲目游走。

这种现象最致命的后果是彻底摧毁了变分量子算法所期望的量子加速优势。变分量子算法的基本加速假设建立在“启发式量子经典混合循环”之上：即我们假设存在一个多项式规模 $O(poly(N))$ 的量子电路，且经典优化器可以通过访问量子计算机，在多项式时间 $O(poly(N))$ 内完成梯度的估计并更新参数。

然而，在贫瘠高原现象中，梯度的方差衰减满足 $Var(\partial C / \partial \theta) \in O(1/2^{N})$。为了能够准确捕捉到这个指数级微小的梯度信号以指导参数更新，经典优化器必须通过多次重复测量（即大量的采样）来克服量子测量的统计散粒噪声。根据采样复杂度理论（如切比雪夫不等式或中心极限定理），要将梯度估计的误差控制在有意义的范围内，所需的采样次数与方差成反比，即 $T \propto 1/Var \in O(2^{N})$。这意味着，为了获取一次有效的梯度更新，量子计算机需要进行指数级的测量次数，这直接将算法的整体时间复杂度从预期的多项式级 $O(poly(N))$ 恶化为了指数级 $O(2^{N})$。在这种指数级时间复杂度的诅咒下，变分算法相比于经典优化算法不再具备任何加速优势，反而可能因为量子硬件的额外开销而表现得更差。

总结而言，贫瘠高原源于随机量子态在希尔伯特空间中展现出的强纠缠与均匀性，它引发的“梯度消失”迫使算法付出指数级的采样代价。这就解释了为什么在设计具有严格多项式时间复杂度保证的变分量子算法时，必须严格约束电路深度、采用具有局部代价函数的架构或利用先验物理知识，以避免陷入这一指数级复杂度爆炸的陷阱。

### Reference answer

ADAPT-VQE（Adaptive Derivative-Assembled Problem Tailored VQE）是一种结合了经典优化与量子计算的混合变分算法。其核心原理在于打破了传统VQE中预先定义好拟设结构的限制，转而采用一种“按需生长”的迭代构建策略。具体而言，算法需要预先定义一个由各种可能的激发算符（通常是由费米子激发算符映射而来的泡利字符串池，如基于UCCSD的算符池）组成的集合。在每一次迭代中，通过量子计算机计算当前量子态对池中每一个算符的参数梯度（通常利用费曼-海尔曼定理，即测量哈密顿量与对应算符的对易子期望值 $\frac{\partial E}{\partial \theta_i} = \langle \psi | [H, A_i] | \psi \rangle$）。随后，经典计算机挑选出梯度绝对值最大的算符（即对当前能量下降贡献最显著的方向），将其以指数形式 $e^{\theta_i A_i}$ 追加到现有拟设线路的末端，并重新优化所有参数。当最大梯度低于设定阈值时，算法收敛并终止。

相较于固定拟设的UCCSD-VQE，ADAPT-VQE的突破性优势在于系统尺寸的压缩和拟设的极致精简。传统的UCCSD拟设包含了所有可能的单双激发，参数数量随体系规模呈 $O(N^4)$ 增长，且线路深度极大。实际上，并非所有的激发模式都对基态能量有显著贡献。ADAPT-VQE通过贪婪算法剔除了冗余项，生成的拟设不仅参数量极低（通常呈 $O(N)$ 增长），且硬件所需的量子门数量大幅减少，实现了针对特定分子和特定基态的“量身定制”。

在计算复杂度与量子加速来源方面，经典全组态相互作用方法的复杂度呈指数级增长 $O(e^N)$。虽然ADAPT-VQE尚未被证明具有严格的多项式时间复杂度保证，但其量子加速来源于量子态在希尔伯特空间中的高效表示。通过量子比特编码指数级的波函数振幅，ADAPT-VQE能够以多项式数量的量子比特探索巨大的态空间，并通过量子测量高效评估哈密顿量期望值和梯度。而经典计算机则被降维为一个参数筛选器和优化器，从而在特定化学体系（如过渡金属络合物或强关联系统）中超越了经典张量网络或近似方法的极限。

在NISQ时代的背景下，ADAPT-VQE具有天然的硬件优势。首先，由于线路深度大幅度缩减，量子态与环境的退相干时间不再成为不可逾越的鸿沟，显著降低了底层门错误率的累积效应。其次，传统深层拟设极易陷入由于希尔伯特空间维度灾难引起的“贫瘠高原”（即梯度消失）问题。ADAPT-VQE由于每次只添加少量结构且保持极少的总参数量，有效维持了高维损失函数的局部凸性，使得基于梯度的经典优化器（如BFGS）能够始终找到有效的优化方向，避免了梯度消失导致的收敛停滞。这种通过牺牲经典计算开销（迭代计算梯度）来换取更短、更精确、更抗噪的量子线路的策略，是当前NISQ阶段解决实际化学问题的极具潜力的途径。

### Prompt

在ADAPT-VQE（自适应变分本征求解器）算法中，其核心机制是通过不断测量算符池中各个候选算符的梯度，并挑选梯度最大者加入到拟设中。然而，在真实的NISQ（含噪声中等规模量子）设备上执行此算法时，由于硬件噪声（如退相干、门错误率）和有限采样的存在，自适应选择机制会面临哪些根本性的挑战？在实际操作中，我们又该如何结合硬件特性来缓解这些局限性，以避免算法陷入错误的优化路径？

### Reference answer

ADAPT-VQE在理论上能够以极少的参数构建接近精确的拟设，但在真实的NISQ设备上执行时，其自适应梯度选择机制面临着极其严峻的挑战。这些挑战主要体现在以下三个维度：

1. 有限采样带来的统计噪声引发的“梯度淹没”：在每次ADAPT-VQE的迭代中，算法必须计算算符池中所有算符的梯度以寻找最大值。由于量子硬件测量的概率本质，要精确估计梯度需要极高的采样次数。在算法收敛的后期，真实的梯度值往往已经非常小，此时由于有限采样造成的统计涨落可能会掩盖真实的梯度信号，导致算法错误地选择了并非最优的算符，甚至无法满足收敛条件而无法终止。

2. 系统性硬件噪声导致的梯度失真与错误收敛：NISQ设备上的单、双比特门错误率以及量子比特的退相干时间限制，会导致量子态在演化过程中丢失信息。由于ADAPT-VQE是一种贪心算法，当前步的选择依赖于上一步构建的量子态。如果由于硬件门错误导致计算出的梯度存在系统性偏差，算法就会沿着错误的优化路径前进，将错误的算符堆叠进拟设中。这种误差的累积不仅会极大增加不必要的电路深度（从而引入更多退相干误差），最终还会导致求得的基态能量严重偏离真实值。

3. 拓扑连通性与SWAP开销的动态放大：由于ADAPT-VQE选出的算符序列是不可预测的，它通常不遵循硬件的原生连通性拓扑。当被选中的双激发算符涉及的量子比特在硬件上不相邻时，必须插入SWAP门。自适应算法极易挑选出跨度极大的非局域算符，导致线路中充斥着高错误率的SWAP操作，使得电路深度迅速突破相干时间的限制。

为了在NISQ设备上缓解这些硬件局限性，研究者通常需要采用以下策略：

首先，在算法层面进行**算符池的先验裁剪**。利用分子对称性（如粒子数守恒、自旋对称性、空间对称性）提前排除那些梯度必定为零的算符，将算符池大小缩减一个数量级，从而成倍减少所需的测量资源，降低统计噪声引发错误选择的概率。

其次，引入**量子误差缓解技术**。在计算梯度时，可以结合零噪声外推（ZNE）或概率误差消除（PEC）技术，通过对不同噪声尺度下的梯度测量结果进行 Richardson 外推，估算出在零噪声下的真实梯度；或者在测量阶段使用虚拟蒸馏技术，以抑制硬件错误导致的梯度失真，确保算法的贪心选择不偏离正轨。

最后，为了防止电路深度剧增引发的退相干灾难，可以结合**NISQ硬件感知的启发式选法**。在评估算符梯度时，不仅考虑梯度的大小，还要将该算符映射到特定硬件拓扑上所需的SWAP开销（即“硬件代价”）作为惩罚项纳入考量。通过优先选择局域性强、硬件映射成本低的算符，能够将线路深度控制在退相干阈值以内。

**1. 量子化学与新材料设计（变分量子本征求解器，VQE）**

**2. 组合优化与物流调度（量子近似优化算法，QAOA）**
金融、物流和人工智能中存在大量的组合优化问题（如旅行商问题、投资组合优化）。QAOA是VQA的一种特殊形式，它通过交替施加“问题哈密顿量”和“混合哈密顿量”来寻找经典难题的近似最优解。以金融领域的信用风险评估或供应链的车辆路径规划为例，QAOA能够在庞大的解空间中高效地寻找高质量的可行解。

**3. 量子机器学习（QML）**

### Reference answer

在量子计算中，提取量子体系哈密顿量的能量（期望值）主要依赖于两种截然不同的范式：变分量子本征求解器（VQE）中的Pauli项测量与量子相位估计（QPE）。<br><br>**数学推导：**<br>在VQE算法中，体系的哈密顿量 $H$ 通常被表示为一系列Pauli算符张量积的线性组合：$$H = \sum_{i} h_i P_i$$其中 $h_i$ 是实数系数，$P_i$ 是作用于 $n$ 个量子比特上的Pauli字符串（如 $X \otimes I \otimes Z$）。为了在量子硬件上测量参数化态 $|\psi(\theta)\rangle$ 的能量期望值，我们将问题转化为测量各个Pauli字符串的期望值并加权求和：$$E(\theta) = \langle \psi(\theta) | H | \psi(\theta) \rangle = \sum_{i} h_i \langle \psi(\theta) | P_i | \psi(\theta) \rangle$$由于Pauli算符的特征值为 $\pm 1$，我们可以通过在计算基（Z基）下测量量子比特来获取其期望值。对于一般的Pauli字符串，需要通过旋转基变换将其转换到Z基。对于 $P_i = X_0 \otimes Y_1 \otimes Z_2$，期望值为：$$\langle P_i \rangle = \sum_{k} p_k (-1)^{f(k)}$$其中 $p_k$ 是测量得到特定比特串 $k$ 的概率，$f(k)$ 是比特串中对应算符为 $-1$ 的特征值的位数奇偶性。<br><br>**对比分析：**<br>1. **量子相位估计（QPE）：**<br>QPE利用量子傅里叶变换，通过受控幺正演化 $U = e^{-iHt}$ 将哈密顿量的特征相位提取到辅助寄存器中。如果输入态具有基态重叠，QPE能以极高概率投影并输出精确的基态能量。<br>*优点*：理论上能提供指数级精度的能量特征值，且无需处理复杂的经典优化问题。<br>*缺点*：需要实现深层次的受控时间演化线路，电路深度大且对噪声极度敏感。此外，它需要大量的辅助比特。<br>*适用场景*：大规模容错量子计算机（FTQC）时代。<br><br>2. **VQE的Pauli项分解测量：**<br>VQE将测量任务分解为许多简单的Pauli字符串期望值的统计平均。通过将不同时刻独立测量的结果在经典计算机上相加，避开了深线路。<br>*优点*：线路深度极浅，抗噪声能力强，非常适合当前中等规模带噪声（NISQ）时代的量子硬件。<br>*缺点*：测量复杂度极高。哈密顿量的Pauli项数量随系统规模指数增长，为达到化学精度所需的测量采样次数极其庞大（方差大）。同时，经典优化器容易陷入局部最优。<br>*适用场景*：NISQ时代的量子化学模拟和材料科学探索。<br><br>**isQ代码实现：**<br>以下代码展示了如何在制备好状态后，针对Pauli串 $X_0 \otimes Y_1 \otimes Z_2$ 进行基变换与测量。由于X基和Y基需分别通过Hadamard门和特定的旋转门转换到Z基，我们可以这样实现：<br>```isQ

变分量子本征求解器（VQE）是量子化学和材料科学中极为重要的算法。我将分四步为您详细拆解其背后的变分原理与上界保证，并最后提供一段追踪算法过程的代码。

**第一步：理解哈密顿量与能量本征态的谱系**
假设我们研究的量子系统存在一个哈密顿量算符 \( H \)。由于 \( H \) 是一个厄米矩阵，根据线性代数中的谱定理，它具有实数特征值和正交的特征向量。我们可以将其写为：
\[ H = \sum_{i} E_i |\psi_i\rangle\langle\psi_i| \]
其中 \( E_0 < E_1 \le E_2 \dots \le E_{N-1} \) 是系统的特征能量，\( |\psi_i\rangle \) 是对应的本征态。我们首要目标是找到最低的特征值 \( E_0 \)，即系统的基态能量。

**第二步：构造试探波函数与能量期望的计算**
在量子计算机中，我们通过一个参数化量子线路（Ansatz）来准备一个试探波函数 \( |\phi(\vec{\theta})\rangle \)。这里的 \( \vec{\theta} \) 是一组我们可以调节的变分参数。
随后，我们在量子计算机上测量这个试探波函数在哈密顿量 \( H \) 下的能量期望值：
\[ E(\vec{\theta}) = \langle\phi(\vec{\theta})| H |\phi(\vec{\theta})\rangle \]
由于 \( H \) 通常可以分解为多个泡利串的加权和 \( H = \sum_j c_j P_j \)，我们可以分别测量每个泡利项 \( P_j \) 的期望，然后再通过经典计算机相加求和。

**第三步：推导上界保证（变分原理的核心）**
为了理解为什么测量出来的能量一定是基态能量 \( E_0 \) 的上界，我们将试探态用真实的哈密顿量本征态展开（即进行线性表示）：
\[ |\phi(\vec{\theta})\rangle = \sum_{i} a_i |\psi_i\rangle \]
由于本征态是正交归一的，归一化条件要求 \( \sum_{i} |a_i|^2 = 1 \)。
现在，将这个展开式代入能量期望的公式中：
\[ E(\vec{\theta}) = \sum_{i,j} a_i^* a_j \langle\psi_i| H |\psi_j\rangle \]
因为 \( |\psi_i\rangle \) 是 \( H \) 的本征态，所以 \( \langle\psi_i| H |\psi_j\rangle = E_i \delta_{ij} \)，这大大简化了我们的推导：
\[ E(\vec{\theta}) = \sum_{i} |a_i|^2 E_i \]
已知基态能量 \( E_0 \) 是所有能量中最小的（即 \( E_i \ge E_0 \)），我们可以进行放缩：
\[ E(\vec{\theta}) = \sum_{i} |a_i|^2 E_i \ge \sum_{i} |a_i|^2 E_0 = E_0 \sum_{i} |a_i|^2 \]
结合归一化条件 \( \sum_{i} |a_i|^2 = 1 \)，我们得出结论：
\[ E(\vec{\theta}) \ge E_0 \]
这就是上界保证的严格数学推导！无论你如何瞎猜试探波函数，无论你的参数 \( \vec{\theta} \) 有多糟糕，算出来的能量永远不会低于真实的基态能量。

**第四步：经典-量子混合优化循环**
既然能量期望总是基态能量的上界，那么我们就可以将寻找基态能量转化为一个最优化问题：
\[ E_0 \approx \min_{\vec{\theta}} E(\vec{\theta}) \]
我们利用经典优化器（如梯度下降或Nelder-Mead等），根据当前测量到的能量期望，不断更新参数 \( \vec{\theta} \)。随着优化进行，试探波函数逐渐逼近真实的基态，能量期望不断下降并最终收敛至 \( E_0 \)。

### Reference answer

<thinking>
1. 分析VQE与NISQ硬件局限的冲突：
VQE将哈密顿量分解为 $H = \sum c_i P_i$。为了得到期望值 $\langle H \rangle = \sum c_i \langle P_i \rangle$，我们需要对每个泡利串进行多次测量以获取样本均值。
NISQ设备的局限性在于：
- 退相干时间（T1, T2）有限，线路深度越深，量子态衰减和散相越严重。
- 两比特门（如CNOT）的保真度远低于单比特门，噪声大。

2. 泡利项分组测量的权衡：
- **不分组策略**：每次运行只测量一个或少数几个相互对易且基变换简单的项。优点是线路浅（基变换通常是单比特的H或HS†），退相干影响小，系统误差低。缺点是总测量次数（shots）呈指数级或高阶多项式级增长，耗时极长，且在长时间运行中易受硬件参数漂移影响。
- **大量分组策略**：利用张量积或幺正变换将多个不对易的泡利项打包到一个组中同时测量（例如通过Clifford变换对角化整个组）。优点是极大减少了测量次数，统计误差收敛快。缺点是需要引入大量的CNOT门和复杂的幺正变换网络来改变测量基，导致线路深度急剧增加。在NISQ设备上，深层线路会导致极快的退相干，测量结果被硬件噪声完全淹没，甚至产生比统计误差更严重的系统偏差。
- **结论**：在硬件受限维度下，最优的分组策略不是“最大化分组”，而是在“降低测量次数（减小统计误差）”与“缩短线路深度（避免退相干带来的系统误差）”之间寻找特定硬件的帕累托最优解。

- 测量YIY：需要在q[0]和q[2]上施加 S† 和 H门（转换Y基到Z基），然后测量。

在当前的NISQ（含噪声中等规模量子）时代，量子硬件面临着量子比特退相干时间极短以及量子门保真度有限的严峻挑战。在VQE算法中，为了求解目标哈密顿量的基态能量，我们需要将哈密顿量分解为多个泡利项 $H = \sum_i c_i P_i$，并通过对量子态的反复测量来估计各项的期望值。在这个硬件局限维度下，泡利项的分组测量策略面临着极为严苛的“线路深度与测量次数”的内在权衡。

从硬件退相干的角度来看，如果我们将哈密顿量分解得非常细，即采用“逐项测量”或“极小分组”策略，虽然每次测量的量子线路非常浅（仅包含拟设线路和少量的单比特基变换门，如H门或S门），可以最大程度地避开退相干影响，保证单次测量的保真度；但这将导致所需的测量总次数呈爆炸式增长。为了达到化学精度，庞大的采样次数不仅耗时极长，还容易受到硬件长时间漂移噪声的影响。

相反，为了减少测量次数，我们通常会采用“泡利项分组”策略，利用相互对易的泡利算符可以通过相同的旋转基矢同时测量的特性来压缩采样量。然而，在硬件层面实现这种复杂的基变换往往需要引入由多级CNOT门构成的纠缠网络（例如Clifford酉算符分解）。由于两比特量子门的错误率通常比单比特门高出一到两个数量级，且门操作时间更长，这使得测量线路深度急剧增加。由于量子比特的纵向弛豫时间（T1）和横向散相时间（T2）有限，过深的线路会使得量子态在测量发生前就已经发生严重退相干。此时，即使统计意义上的测量次数再少，得到的期望值也会因为系统性的硬件噪声而偏离真实值，甚至导致VQE优化完全失败。因此，在NISQ设备上，最优的测量策略必须结合具体的硬件拓扑结构、门保真度和退相干时间来进行定制化分组，而非盲目追求理论上的最大分组。

下面是使用isQ语言编写的代码示例，展示了如何为一个3比特量子态构建测量线路，并分别针对 $X_0 X_1 I_2$ 和 $Y_0 I_1 Y_2$ 施加不同的基变换逻辑：

```isq
import std;

// 声明3个全局量子比特
qbit q[3];

// 测量 X_0 X_1 I_2 的线路子程序
procedure measure_xx_basis() {
    // 施加拟设门 (此处使用简单的纠缠态作为示例)
    H(q[0]);
    CNOT(q[0], q[1]);
    CNOT(q[1], q[2]);

    // 为了在计算基(Z基)下测量X，需要施加Hadamard门进行基变换
    // 因为 P = X(0) X(1) I(2)，我们只需改变前两个比特的基
    H(q[0]);
    H(q[1]);

    // 执行测量并记录结果 (isQ中使用M操作)
    int r0 = M(q[0]);
    int r1 = M(q[1]);
    int r2 = M(q[2]);
}

// 测量 Y_0 I_1 Y_2 的线路子程序
procedure measure_yy_basis() {
    // 施加相同的拟设门
    H(q[0]);
    CNOT(q[0], q[1]);
    CNOT(q[1], q[2]);

    // 为了在计算基下测量Y，需要施加 S† 和 H 门
    // 因为 P = Y(0) I(1) Y(2)，我们改变第0和第2个比特的基
    // 逆S门(inv S)将Y旋转到X，再通过H门将X旋转到Z
    inv S(q[0]);
    H(q[0]);
    
    inv S(q[2]);
    H(q[2]);

    // 执行测量
    int r0 = M(q[0]);
    int r1 = M(q[1]);
    int r2 = M(q[2]);
}

procedure main() {
    // 实际运行中，我们会多次调用上述子程序以统计期望值
    // 此处仅调用一次作为基变换和测量的演示
    measure_xx_basis();
    
    // 重置量子比特状态以便进行下一次不同基的测量
    // 注意：在实际硬件中，每次测量前需要重新初始化和运行拟设线路
    for i in 0:3 {
        X(q[i]); // 假设通过简单的X门辅助重置，具体取决于硬件特性
    }
    
    measure_yy_basis();
}
```

### Reference answer

<thinking>
原始的 ADAPT-VQE 依赖于费米子算符池（如单双激发算符），导致算符池大小随系统规模呈高阶多项式甚至指数级增长，且每次迭代都需要计算所有候选算符的梯度，经典与量子通信开销巨大。针对这些瓶颈，业界提出了几个关键的优化变体：

1. **Qubit-ADAPT-VQE**: 该变体将费米子池替换为纯的泡利算符池。由于去除了 Jordan-Wigner 变换带来的长 CNOT 链，算符池大大减小，且作用域更局部。虽然可能需要更深的电路来达到化学精度，但大大减少了每步挑选算符的经典计算开销。

2. **Tetris-ADAPT-VQE**: 针对顺序添加算符导致线路过深的问题，Tetris-ADAPT 借鉴了俄罗斯方块的思想，在评估梯度后，将互不冲突（即作用在不同量子比特上）的多个泡利算符在同一层中并行添加。这极大地压缩了线路深度。

3. **Iterative Qubit-Excitation Based VQE (IQEB-VQE)**: 结合了 qubit 激发和自适应选择的优点，直接在量子比特层面上定义具有物理意义的激发池，进一步平衡了池大小和收敛速度。

const N = 4;
qbit q[N];

// 演示 Qubit-ADAPT-VQE 中的一种典型两比特池算符：exp(-i * theta * X[0] * Y[1])
// 这种算符作用更局部，且不需要像费米子激发那样引入大量的宇称辅助比特
procedure apply_pauli_pool_gate(double theta, int c, int t) {
    // 为了实现 exp(-i * theta * X[c] * Y[t])
    // 首先对控制比特进行 H 变换，将 X 映射为 Z
    H(q[c]);
    
    // 对目标比特进行 Rx(pi/2) 变换，将 Y 映射为 Z
    Rx(pi/2, q[t]);
    
    // 利用 CNOT 门将两比特的 Z 张量积映射为单比特 Z 旋转
    CNOT(q[c], q[t]);
    
    // 应用核心的参数化旋转
    Rz(2.0 * theta, q[t]);
    
    // 逆向解除纠缠
    CNOT(q[c], q[t]);
    
    // 恢复目标比特的基矢
    Rx(-pi/2, q[t]);
    
    // 恢复控制比特的基矢
    H(q[c]);
}

procedure main() {
    // 初始化分子系统的 Hartree-Fock 基态
    // 假设前两个轨道占据电子
    X(q[0]);
    X(q[1]);

    // 假设经过经典梯度计算后，当前迭代选出的是作用在 q[0] 和 q[1] 上的泡利算符
    // 并且通过经典优化器寻找到了最优参数 0.543
    double optimal_theta = 0.543;
    
    // 将该池算符自适应地拼接到线路中
    apply_pauli_pool_gate(optimal_theta, 0, 1);
    
    // 在真实的自适应环境中，此处会继续添加后续选出的算符
    // 例如下一次可能选出 q[1] 和 q[2] 的算符

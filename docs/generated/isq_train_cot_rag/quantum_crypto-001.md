纠缠交换的核心确实在于中间节点对两个局域纠缠粒子进行贝尔态测量。一旦测量完成，远端的两个粒子确实会瞬间“坍缩”到同一个纠缠态上（例如 $|\Phi^+\rangle$ 或 $|\Psi^-\rangle$ 等）。然而，这种瞬间的量子关联并不能用来传递任何有用的信息（如密钥）。因为远端节点在不知道中间节点贝尔态测量结果的情况下，他们对自己粒子的任何测量结果看起来都是完全随机的 0 和 1，且彼此之间毫无关联。根据量子不可通信定理，没有经典信息的辅助，这种瞬间的量子纠缠无法用于传递信息，更不可能超光速分发密钥。

**陷阱二：量子密钥分发绝对离不开经典信道**
在量子密码学（如基于纠缠的 E91 协议或量子中继器架构）中，经典信道是不可或缺的。中间节点进行贝尔态测量后，必须通过经典信道将测量的具体结果（即坍缩到了四个贝尔态中的哪一个）发送给通信双方（Alice 和 Bob）。Alice 和 Bob 只有在接收到这个经典信息后，才能知道自己手中的量子比特处于什么状态，进而通过特定的基矢选择或局域酉变换（如施加 X 门或 Z 门）来对齐他们的状态。此外，为了检测是否存在窃听者，Alice 和 Bob 也必须通过经典信道公开比对一部分测量结果以计算误码率。如果像该观点所述“完全不需要依赖经典信道”，那么双方提取出的随机序列将是毫不相干的纯随机噪声，根本无法生成一致的密钥。经典信道的安全性并不依赖于物理上无法窃听，而是利用量子态不可克隆等物理定律，一旦窃听者介入量子信道，误码率就会飙升从而被察觉。

这就是量子纠缠最绝妙的地方。在日常的宏观世界里，你可以拆开一个普通包裹，看完后再原样封好，收件人根本发现不了。但在这个量子魔法世界里，盲盒的状态在被打开（测量）之前是模糊的、未决定的。如果间谍Eve想要偷看，她就**必须**强迫这个盲盒做出决定（变成红球或蓝球）。

总结来说，量子纠缠在密钥分发中扮演了一个“自带防窃听警报的宇宙级随机数生成器”的角色。它利用了“未打开前状态未知”和“一旦观测就被破坏”这两个奇妙的物理直觉，让Alice和Bob可以确信：他们之间生成的密码，不仅连制造者都不知道，而且任何试图窥探的间谍都必定会留下无法抹除的痕迹，从而保证了密钥的绝对安全。

### 为什么是25%的误码率？
在BB84协议中，Alice随机选择Z基（|0>, |1>）或X基（|+>, |->）发送量子比特，Bob也随机选择这两种基进行测量。当Eve进行拦截-重发攻击时，她必须随机选择一个基进行测量，然后将测量后的量子态发给Bob。

在公开比对阶段，Alice和Bob只保留他们**选择了相同基**的数据。我们仅针对这部分保留的原始密钥分析Eve引入的误码：
1. **Eve猜对了基（概率为1/2）**：Eve的测量基与Alice和Bob一致。这种情况下，测量不会改变量子态，Eve准确获取了比特信息，Bob最终测量的结果与Alice完全一致，**无误码产生**。
2. **Eve猜错了基（概率为1/2）**：Eve的测量基与Alice和Bob正交。此时Eve的测量会使得原有的量子态坍缩到她所选择的基矢上。例如，如果Alice发送的是X基的|+>态，Eve用Z基测量，态将等概率坍缩为|0>或|1>。随后Eve将坍缩后的态发送给Bob。当Bob使用X基进行测量时，由于|0>和|1>在X基下是完全叠加的（即|<+|0>|^2 = |<+|1>|^2 = 0.5），Bob测得正确结果的概率为1/2，测得错误结果的概率也为1/2。因此，在此情况下，**引入的误码率为50%**。

综合以上两种情况，整体引入的误码率为：
$$ QBER = P(\text{Eve选对基}) \times 0 + P(\text{Eve选错基}) \times \frac{1}{2} = \frac{1}{2} \times 0 + \frac{1}{2} \times \frac{1}{2} = 25\% $$

### Reference answer

量子数字签名（Quantum Digital Signatures, QDS）是量子密码学中的重要协议，旨在提供信息论安全的不可伪造性和不可抵赖性。与经典数字签名依赖数学困难问题不同，QDS利用量子力学的基本特性（如量子不可克隆定理和测量坍缩）来保证安全。在Gottesman-Chuang提出的开创性QDS方案中，签名通常由非正交量子态（如 |0> 和 |+>）来表示。

为了直观展示这一概念，我们可以设计一个简化的量子电路模型。在该模型中，我们使用两个量子比特：一个代表待签名的经典消息比特，另一个代表私钥或签名的量子载体。发送方通过量子门操作（如CNOT门）将消息比特的信息编码到签名量子比特的纠缠态中，完成“签名生成”。随后，接收方利用公开的验证密钥或协议结构，通过逆操作将纠缠解除并进行测量，完成“签名验证”。如果测量结果恢复为预期的初始态，则签名有效。

以下是使用isQ量子编程语言编写的演示程序：

```isq
import std;

// 声明全局量子比特用于消息和签名操作
qbit q[2];

procedure main() {
    // q[0] 作为待签名的消息比特，q[1] 作为签名比特（私钥载体）
    // 假设 Alice 想要签名的消息比特 m = 1，初始私钥态 k = 1
    X(q[0]);
    X(q[1]);

    // --- Alice 的签名生成阶段 ---
    // Alice 利用 CNOT 门将消息比特的状态映射到签名比特上，建立纠缠。
    // 这模拟了利用量子操作将经典消息与私钥结合生成量子签名态的过程。
    CNOT(q[0], q[1]);

    // --- 信道传输 ---
    // Alice 将消息比特 q[0] 和签名比特 q[1] 发送给验证者 Bob。
    // 在实际QDS中，可能会有多个接收者，且签名态为非正交态以防止伪造。

    // --- Bob 的签名验证阶段 ---

    // Bob 执行 CNOT 操作尝试解纠缠。
    CNOT(q[0], q[1]);

    // Bob 对两个量子比特进行投影测量
    int r_msg = M(q[0]);
    int r_sig = M(q[1]);

    // Bob 的经典后处理与判决
    // 如果没有遭到篡改且信道无噪声，由于 CNOT 门的自逆特性，
    // q[0] 和 q[1] 必然会恢复到初始的 |1> 状态。
    if (r_msg == 1 && r_sig == 1) {
        // 验证成功，确认消息来自Alice且未被篡改
        // 在真实量子计算机中，可以通过经典寄存器记录该结果
    } else {
        // 验证失败，拒绝该消息
    }
}
```

## Session 2 (later, 2026-07-10) — ablation wiring + `main()` contract

### Method
Two independent deliverables, both unblocking the next NPU ablation sweep.
Full record: `docs/ablation-wiring-and-main-program-contract-2026-07-10.md`.

1. **Ablation launcher wiring (per-artifact scoring plan Phase 4).**
   Extended `ABLATION_PRESET` (A–F) + `PIPELINE_MAX_ROUNDS` env-var knobs
   across all three student launchers (ASI1/27B, ASI2/35B, ASI3/35B). Each
   preset maps to a triple of trainer flags
   (`--reward-weighted-nll` / `--per-artifact-kl-gate` /
   `--partial-credit-upweight`), recorded in `run_config.json` and passed
   to `training/qwen_sft_peft_kl.py`. The round-cap auto-stops the
   orchestrator after N rounds for a fixed ablation budget.
2. **`main()`-program question contract (machine-enforced).** The coding
   teacher gate (`TEACHER_QGATE_PROMPT_TEMPLATE`) now returns a
   `requires_full_program` boolean; the acceptance logic rejects questions
   that don't ask for a full runnable program with a `def main():` entry
   point + `if __name__ == "__main__": main()` + a printed concrete result.
   New stat `qgate_coding_not_full_program`; new metadata field
   `qgate_requires_full_program`.

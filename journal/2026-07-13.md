### N2 → RL pipeline seam (new)

`scripts/rl_distill_pipeline.py` now supports teacher-free grading via
the trained critic-LoRA:

```python
TeacherConfig(
    ...,
    critic_mode="local_lora",            # default: "glm52_api"
    critic_adapter_path="models/critic-lora-v1",
)
```

When `critic_mode="local_lora"`, `teacher_eval()` routes to
`_critic_lora_eval()`, which builds the same critic prompt used by
`prepare_critic_sft.py` and runs the adapter. The on-box inference is
delegated to the ASI launch script (cannot run 27B on CPU); the seam
raises a clear `RuntimeError` rather than silently falling back to
GLM5.2. Backwards-compatible: all 41 existing pipeline tests pass
unchanged (positional `TeacherConfig` construction preserved).

### Key design decisions

1. **Corruption-proof DPO signal** (N3, N7, N10): the rejected side is
   *constructed to fail* on a specific axis (ImportError / TypeError /
   traceback-raising), so the model cannot learn to prefer it. Same
   principle as N1.
2. **Execution-grounded verification** (N4, N5, N8, N10): every emitted
   chosen/completion side is verified by subprocess against the task's
   `tests.py` or against expected stdout. No model judge involved.
3. **Composability** (N9, N10): N9 uses the N3 mutation helpers to generate
   K candidates; N10 uses the N3/N7 failing variants to generate
   traceback prompts. The lines compose into a full self-repair stack:
   N2 critic → N9 selector → N10 repair.
